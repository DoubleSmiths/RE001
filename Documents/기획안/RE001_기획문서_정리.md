## 1. 게임 흐름

```
모험가협회 → 임무 수행 → 모험가 등급 상승 → 컨텐츠 해금
여정        → 경험치 / 재료 수급 / 임무 완수 / 몬스터 포획
신전        → 경험치로 레벨업 → 전직
기술        → 전직 시 해당 직업 기술 습득
           → 하수인 동화율 100% 시 해당 하수인 기술 습득
하수인      → 몬스터 포획 성공 시 하수인 등록 → 전투 동반
           → 동일 하수인 재포획 시 능력치 및 동화율 상승
장비        → 수급한 재료로 제작
```

## 2. 진행 방식

### 씬 흐름
```
메인화면(계정로그인) → 로비(마을) → 각 장소
```

### 접근 가능 장소

| 장소 | 주요 기능 | 구현 상태 |
|------|-----------|-----------|
| 모험가협회 | 퀘스트 수주, 등급 관리 | - |
| 연금공방 | 물약 / 기술 제작 | - |
| 신전 | 레벨업, 전직 | - |
| 대장간 | 장비 제작 및 강화 | - |
| 여정(전투) | 몬스터 사냥, 경험치, 재료 수급 | - |

### 핵심 기능 요약
- 퀘스트를 통한 게임 컨텐츠 해금
- 전직 시스템
- 몬스터 드롭 아이템으로 장비 제작 및 강화
- 몬스터 사냥
- 물약 제작

| 항목 | 내용 |
|------|------|
| 표시 재화 | 골드(금화), 다이아(결정) |
| 증가 시 | 초록색 `#00FF00` 으로 잠깐 빛남 |
| 감소 시 | 빨간색 `#FF0000` 으로 잠깐 빛남 |

**텍스트 스타일:**
- 금화 TEXT — Font: `PF_Stardust` (고정), Color: `FFFFFF`, Outline: `FFF600` alpha 80, offset (0.2, -0.2)
- 결정 TEXT — Font: `PF_Stardust` (고정), Color: `00F3FF`, Outline: `FFF600` alpha 80, offset (0.2, -0.2)

**환경설정 버튼 애니메이션:**
- DoTween Scale / Duration 0.07 / Delay 0 / Ease OutQuad / Loops 2 / Loop Type Yoyo / To 0.75 (Uniform Scale)

## 6. 능력치 시스템

### 6-1. 기본 스탯 (능력 점수 배분 대상)

| 스탯 | 효과 | 최대 배분 |
|------|------|-----------|
| 근력 | 배분된 각 수치마다 물리공격력 +1 | 제한 없음 |
| 체력 | 배분된 각 수치마다 최대&현재 HP +30 | 제한 없음 |
| 민첩 | 공격 딜레이 -0.02초, 회피율 +0.1% | **최대 100** |
| 마력 | 배분된 각 수치마다 마법공격력 +1 | 제한 없음 |

> 모든 증가량 및 최대 할당 수치는 조정 가능하게 구현
> 모든 초기 능력치는 0 (조정 가능)

### 6-2. 상세 능력치 14종

| # | 능력치 | 초기값 | 설명 |
|---|--------|--------|------|
| 1 | 물리공격력 | 10 | 물리 타입 공격의 피해량에 영향 |
| 2 | 마법공격력 | 10 | 마법 타입 공격의 피해량에 영향 |
| 3 | 치명타 | 0.00% | 공격이 치명타로 적중할 확률. 100% 이상 수치 가능하나 적용은 100%까지 |
| 4 | 치명타피해 | 150% | 치명타 적중 시 표기된 %로 피해량을 곱함 (150% = 1.5배) |
| 5 | 명중률 | 80.0% | 공격이 적에게 적중할 확률 |
| 6 | 공격속도 | 100% | 기본공격 1회 애니메이션 Speed |
| 7 | 최대체력 | - | 신체 내구력. 0이 되면 사망 |
| 8 | 방어력 | 0 | 모든 타입의 최종 피해량에서 수치만큼 감소. 최종 피해량은 음수 불가 |
| 9 | 물리저항 | 0.00% | 물리 피해 받을 때 해당 %만큼 피해량 감소 |
| 10 | 마법저항 | 0.00% | 마법 피해 받을 때 해당 %만큼 피해량 감소 |
| 11 | 회피율 | 0.00% | 모든 타입의 공격을 해당 %만큼 회피하여 피해 무시 |
| 12 | 회복력 | 0.0% | 체력 회복 관련 모든 효과를 표기된 %로 곱하여 적용 |
| 13 | 성장률 | 100% | 레벨 경험치 획득 시 표기된 %로 곱하여 적용 |
| 14 | 획득률 | 100% | 몬스터 드롭률에 표기된 %로 곱하여 적용 |

### 6-3. 증가율 & 증폭률

적용 대상: 물리공격력, 마법공격력, 최대체력, 방어력

```
최종 능력치 = 기본 × (증가율 + 1) × 증폭률
```

| 구분 | 표기 | 설명 |
|------|------|------|
| 증가율 | +n% | 덧셈형 배율 |
| 증폭률 | ×n | 곱셈형 배율 |

- 해당 4가지 능력치 박스 클릭 시 UI 확장 → 증가율과 증폭률 세부 확인 가능
- 확장 전 표기 능력치는 **최종 능력치**
- 근력/체력 등 스탯으로 오르는 수치는 **기본 수치**가 오르는 것

### 6-4. 능력 점수

- 레벨업 시마다 n점 지급
- 별도 방법으로도 획득 가능 (추후 기획)
- 능력점수 초기화 기능 예정 (아이템 사용)
- 배분 방법: 능력치 칸의 `<>` 버튼으로 조절
- `[배분 능력치 초기화]` 버튼: 배분된 능력치 초기화
- `[배분 능력치 확정]` 버튼: 배분된 능력치 적용

## 7. 데미지 처리 방식

### 판정 순서

```
Step 1. 공격자 명중률 판정
  - 명중 성공 → Step 2
  - 명중 실패 → 빗나감
  - 명중률 100% 이상이면 Step 1 생략

Step 2. 피격자 회피율 판정
  - 회피 성공 → 피해 없음
  - 회피 실패 → Step 3
  - 공격자 명중률 > 100% 이면: 피격자 회피율 - (공격자 명중률 - 100%) 로 계산

Step 3. 피해 계산
  (i)  BASE DMG = 공격자의 해당 공격타입 공격력 × 스킬 데미지 배수 × 치명타피해(해당 시)
  (ii) DMG      = BASE DMG - (BASE DMG × 피격자의 해당타입저항) - 방어력
  (iii)FINAL DMG = DMG × (1 + 피해증폭)
```

> 피해증폭 수치는 전투 UI 하단 참고 (별도 기획 페이지 예정)

## 8. 인벤토리 시스템

### 소지품 (Inventory)

| 항목 | 내용 |
|------|------|
| 슬롯 종류 | 열린칸 / 닫힌칸 |
| 총 슬롯 수 | 25칸 (조정 가능) |
| 아이템 최대 개수 | 슬롯당 999개 |
| 정렬 방식 | 첫 줄 왼쪽부터 → 오른쪽 순으로 자동 배치 |
| 스크롤 | Scroll Bar로 구현 |

**동작 규칙:**
- 획득한 아이템은 열린칸에 자동 보관
- 열린칸이 꽉 찼거나 한 아이템이 999개를 초과하면 알림 팝업 출력 → 해당 아이템 획득 불가
- 닫힌칸은 아이템 또는 퀘스트를 통해 하나씩 해금
- `[정렬]` 버튼 클릭 시: 빈 자리 없이 첫 줄 왼쪽부터 순서대로 재정렬

### 귀중품

- `[귀중품]` 버튼 클릭 시 별도 팝업 호출
- 퀘스트/게임 진행에 필요한 중요 아이템 보관
- 소지품 열린칸 부족으로 퀘스트 진행이 막히는 상황 방지 목적

## 10. UI 상세 스펙

### 폰트 설정

| 용도 | 폰트명 | 조건 |
|------|--------|------|
| NPC 대화 | `Cafe24 Klassic` | 영/한 동일 적용 |
| 메뉴명, 아이템명, 설명 (영어) | `PF_Stardust` | 언어 설정 = 영어 |
| 메뉴명, 아이템명, 설명 (한국어) | `Cafe24 DOSSaemmul` | 언어 설정 = 한국어 |
| 모든 숫자 TEXT | 별도 지정 (고정) | 언어 설정과 무관 |

**예외 처리:**
- Player Bar의 레벨 정보: 언어 무관 항상 `Lv.#` 형식
- 환경설정 팝업의 언어 선택 부분: 언어 무관 고정 표기

**아웃라인 기본 규칙:**
- 모든 TEXT는 별도 언급 없으면 **검은색 Outline** 적용
- 다른 색상의 Outline이 필요한 경우 해당 기획서 페이지에 명시

### 팝업 공통 레이어 (BlackBG_Layer)

모든 팝업은 화면 전체 크기의 검은색 레이어를 지님

| 항목 | 내용 |
|------|------|
| Sprite | None |
| Color | `#000000` alpha 220 |
| OnEnable Anim | DoTween Fade / Duration 0.3 / Delay 0 / Ease OutQuad / Loops 1 / From 0 |
| Manager | OnEnable → Restart / OnDisable → Rewind |
| 클릭 동작 | BlackBG_Layer 클릭 시 팝업 Disable 애니메이션 재생 후 닫힘 |

## 11. 퀘스트 추적 UI (QuestFollow)

### 기획 의도
플레이어가 목적성을 잊지 않도록 무엇을 해야 할지 간단한 가이드 역할

### 상태 흐름
```
초기 시작 상태 → 의뢰 수주 시 → 의뢰 진행중 → 의뢰 목표 달성 시 → 의뢰 완료
```

- 모험가협회에서 의뢰 수주 시 Active
- 모든 임무는 **몬스터 드롭 아이템 n개를 모으는 방식**

### 애니메이션

| 이벤트 | 타입 | Duration | Delay | Ease | Loops | 값 |
|--------|------|----------|-------|------|-------|-----|
| 등장 | DoTween Move | 0.5 | 0 | OutCubic | 1 | To (50, -2, 0) |
| 퇴장 | DoPlayBackward | - | - | - | - | - |
| 의뢰 완료 시 | Particle | - | - | - | - | `Quest_Done_Effect` 재생 |

### 사용 Asset
`message_popup_bg_default`, `shop_frame_glow_left`

### 색상 스펙

| 항목 | 색상 |
|------|------|
| Layer1 배경 | `#000000` |
| 진행중 | `#FFC84E` |
| 완료 | `#57FA00` |

**퀘스트 아이템 보유량 텍스트 색상:**

| 조건 | 색상 |
|------|------|
| 보유량 = 0 | `#FF0000` |
| 0 < 보유량 < 요구량 | `#FEA400` |
| 보유량 >= 요구량 | `#00FF00` |

표시 형식: `[퀘스트아이템 이름]  (현재보유량 / 요구량)`
→ 아이템 습득 시마다 보유량 텍스트 갱신
