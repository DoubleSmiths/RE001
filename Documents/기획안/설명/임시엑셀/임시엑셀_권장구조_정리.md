**개요**

현재 `임시엑셀` 구조는 전반적으로 파서와 잘 맞습니다. 다만 운영 데이터로 커질 때 헷갈리기 쉬운 부분이 있어서, 아래 항목만 정리해두면 안정성이 많이 올라갑니다.

**QuestData.xlsx**

| 파일 | 시트 | 현재 상태 | 권장 수정 | 이유 |
|---|---|---|---|---|
| QuestData.xlsx | Quest | 전반적으로 양호 | `QuestName` 빈 값 제거 | 디버깅과 운영 확인이 쉬워짐 |
| QuestData.xlsx | Quest_Condition | 헤더가 `CompleteType`, `CompleteTarget` | `ConditionType`, `Target`으로 변경 | 실제 파서 의미와 맞춤 |
| QuestData.xlsx | Quest_Notify | 양호 | 유지 | 현재 구조로 충분 |
| QuestData.xlsx | Quest_Unlock | 양호 | 유지 | 현재 구조로 충분 |
| QuestData.xlsx | _Ref | 규칙 설명 있음 | 헤더 의미와 `Target` 규칙 추가 | 작업자 혼동 방지 |

**ItemData.xlsx**

| 파일 | 시트 | 현재 상태 | 권장 수정 | 이유 |
|---|---|---|---|---|
| ItemData.xlsx | InventoryItem | 양호 | 유지 | 현재 파서와 잘 맞음 |
| ItemData.xlsx | RequisiteItem | 양호 | 유지 | 현재 파서와 잘 맞음 |
| ItemData.xlsx | HPPotion | 단계별 데이터는 좋음 | `NextDataId` 컬럼 추가 | `DataId + 1` 같은 암묵 규칙 제거 |
| ItemData.xlsx | HPPotion | 재료 컬럼 존재 | 재료 의미를 “해당 행 포션 제작 비용”으로 고정 | 제작 로직과 UI 기준 통일 |
| ItemData.xlsx | SpeedPotion | HPPotion과 동일 패턴 | `NextDataId` 컬럼 추가 | 후속 시스템 확장 시 안전 |
| ItemData.xlsx | 전체 | 숫자가 `1001.0`처럼 보일 수 있음 | ID 컬럼 서식 통일 | 과학 표기/소수 표기 방지 |

**PlayerStatusData.xlsx**

| 파일 | 시트 | 현재 상태 | 권장 수정 | 이유 |
|---|---|---|---|---|
| PlayerStatusData.xlsx | PlayerStatusData | 구조는 양호 | `StartSkill`, `StartSkill_Lv` 타입 설명 수정 | 현재 파서는 줄바꿈 다중값으로 읽음 |
| PlayerStatusData.xlsx | PlayerStatusData | 타입 행 일부 단일값처럼 보임 | `multiline string`, `multiline int` 명시 | 작업자가 셀 입력 규칙을 바로 이해 가능 |

**권장 운영 규칙**

| 항목 | 권장 규칙 |
|---|---|
| Quest_Condition 헤더 | `QuestID | Order | ConditionType | Target` |
| HPPotion 재료 의미 | `NeededItem_ID / NeededItem_Amount`는 해당 행 포션을 제작하기 위한 비용 |
| 다음 단계 연결 | `NextDataId`로 명시 |
| ID 컬럼 | 가능하면 정수/텍스트 서식으로 고정 |
| NOTE 컬럼 | 파싱 제외 메모 컬럼으로만 사용 |
| StartSkill 입력 | 셀 내부 줄바꿈으로 여러 값 입력 |

**이번에 만든 수정본 반영 내용**

| 파일 | 반영 내용 |
|---|---|
| QuestData.xlsx | `Quest_Condition` 헤더 수정, 1번 퀘스트 이름 보완, `_Ref` 보강 |
| ItemData.xlsx | `HPPotion`, `SpeedPotion`에 `NextDataId` 추가 |
| PlayerStatusData.xlsx | `StartSkill`, `StartSkill_Lv` 타입/설명 문구 보강 |
