 1. 새로 만들어야 할 구글시트 (7종)  ★중요★
==================================================================
아래 7종은 현재 손편집 JSON → 로컬 .xlsx 로만 관리됨
(Assets/@Resources/Data/Excel/). 게임은 이미 전부 로드해서 사용 중
(DataManager.cs 43~67행). 디자이너가 구글에서 편집할 수 있도록
구글시트로 신규 생성 필요.

시트 포맷 규약(기존 PlayerStatus와 동일):
  Row0 = 필드명 / Row1 = 타입 / Row2 = 한글설명 / Row3+ = 데이터
  리스트 셀은 콤마(,)로 구분.

------------------------------------------------------------------
(1) SkillData  ─ 능력/스킬 마스터 (현재 20행)
------------------------------------------------------------------
 컬럼(필드 / 타입 / 한글설명):
  DataId          int     능력 고유 ID
  Name            string  이름(한)
  Description     string  설명(한)
  NameEng         string  이름(영)
  DescEng         string  설명(영)
  IconLabel       string  아이콘 라벨
  Category        enum    분류(Talent 등)
  SkillActiveType enum    Active/Passive
  StatType        string  버프 대상 스탯
  StatBonus       float   레벨당 버프 수치
  MaxLevel        int     최대 등급
  MemoryCapacity  int     기억력 점유(0=재능)
  Story           string  능력 이야기(한)
  StoryEng        string  능력 이야기(영)
  Source          enum    출처(Class/Minion/Equip/Npc/Unlimited)
  RequiredMinionId   int  요구 미니몬 CreatureId
  RequiredEquipId    int  요구 장비 DataId
  RequiredItemId     int  요구 재료 ItemId
  RequiredItemCount  int  요구 재료 개수
  NpcLocation     string  학습 NPC 장소
  RoleTypes       list    종류(Skill,Spell,Def,Util 콤마)
  TriggerType     enum    발동(None/Probability/Time)
  Conditions      list    발동조건(콤마)
  ProcChance      float   확률 발동 %
  Cooldown        float   시간 발동 쿨(초)
  ActiveContext   enum    맥락(InBattle/OutOfBattle/Always)
  ConditionValue  float   조건 파라미터(LowHp%)
  Effect          enum    효과(Heal/BonusDamage/Buff)
  EffectStat      string  Buff 대상 스탯
  EffectValue     float   효과 수치
  EffectDuration  float   Buff 지속(초,0=전투끝)

 3. Travel 시트 점검
==================================================================
 TravelNodeData(JSON)에 아래 신규 노드 2개 지역이 들어 있음:
   - 22000/22100 : Whispering Cave (속삭이는 동굴) + 입구
   - 23000/23100 : Ruined Sanctum (폐허가 된 성소) + 입구
 → 이 노드들이 Travel 구글시트에도 실제로 있는지 확인.
   (JSON엔 있으나 시트에 없다면, 다음 파싱 때 사라짐. 시트에 노드 행도 같이 유지 필요.)
 → 노드의 Name 컬럼은 위 2-(A)에서 추가하는 로컬라이즈 키와 일치해야 함.
   (Sprite: WhisperingCave_Img / WhisperingCave_Entry_Img /
            RuinedSanctum_Img / RuinedSanctum_Entry_Img 도 자산 존재 확인)
