# 비공개 테스트 — 재미 검증 계획 · 설문지

기준일 2026-09-30. 구글 플레이 개인 계정은 정식 출시 전에 **테스터 12명 이상이 14일 연속** 비공개 테스트에 참여해야 한다
(`Store/Release_Checklist.md` 2-4). 이 14일을 재미 검증에 쓴다. 지금까지의 검증은 자동 봇(전 구간 플레이스루)과 개발자 확인뿐이라
"막히지 않는다"만 확인됐고 "재미있다"는 확인되지 않았다.

## 무엇을 재나

| 질문 | 근거 | 목표(가설) |
|---|---|---|
| 첫 10분이 재미있나 | 설문 B1 | 평균 4.0 / 5 이상 |
| 내일 또 켤 것 같나 | 설문 B6 · 기록의 접속 횟수 | "예" 60% 이상, 7일째에도 접속 40% 이상 |
| 진행 속도 | 설문 C1 · 기록의 **Lv10·20·30 도달 시각**, 돌파 수 | "적당" 50% 이상. Lv20 이 첫 1시간 안 |
| 어디서 막히나 | 기록의 **가장 막힌 곳**(보스 실패), 쓰러짐 | 같은 보스에서 테스터 절반 이상이 3번 넘게 실패하면 수치 조정 |
| 과금·광고 거부감 | 설문 D1~D3 · 기록의 광고·소환 횟수 | 광고를 스스로 본 사람이 절반 이상, 거부감 "크다" 20% 이하 |
| 헷갈린 화면 | 설문 E1 | 같은 화면이 3명 이상 나오면 안내를 고친다 |

## 테스터 안내문(복사해서 보낸다)

> 미니몬 퀘스트 비공개 테스트에 참여해 주셔서 고맙습니다. 14일 동안 편하게 플레이해 주세요(매일 조금씩이라도 켜 주시면 큰 도움이 됩니다).
> 1일째와 7일째에 아래 설문을 부탁드립니다. 설문 마지막 칸에는 게임의 **설정 → [플레이 기록]** 을 누르면 복사되는 기록을 붙여 넣어 주세요.
> 기록에는 플레이 시간·레벨·스테이지·광고/소환 횟수만 들어 있고, 기기 밖으로 자동 전송되지 않습니다.

## 설문지(구글 설문지에 옮긴다 — 1일째·7일째 같은 문항)

**A. 기본**
- A1. 기기(모델명) — 자유
- A2. 평소 즐기는 장르(복수): 방치형 / RPG / 수집형 / 액션 / 기타

**B. 재미 — 1(전혀 아니다) ~ 5(매우 그렇다)**
- B1. 처음 10분이 재미있었다
- B2. 전투 손맛이 좋았다(누르면 벤다 · 방패 · 패링)
- B3. 강해지는 게 느껴졌다(훈련 · 장비 · 유물)
- B4. 다음에 뭘 해야 할지 분명했다(퀘스트 · 스테이지)
- B5. 마을(사람들 · 의뢰 · 이야기)과 미니몬(포획 · 동행)이 재미있었다
- B6. 내일도 켤 것 같다 — 예 / 아마도 / 아니오
- B7. 가장 재미있었던 순간 — 자유
- B8. 가장 지루했던 순간 — 자유

**C. 진행 속도**
- C1. 진행 속도는 — 너무 빠르다 / 적당하다 / 너무 느리다
- C2. 오래 막혔던 곳이 있다면 어디, 왜 — 자유

**D. 상점 · 광고**
- D1. 광고를 스스로 본 적이 있다 — 예 / 아니오 (예라면 어떤 보상 때문에)
- D2. 광고·상점에 거부감이 — 없다 / 조금 있다 / 크다
- D3. 실제 출시라면 사고 싶은 상품(복수): 시작 패키지 · 월정액 · 성장 패스 · 광고 제거 · 의상 · 없음

**E. 헷갈림 · 버그**
- E1. 무엇을 하는 화면인지 모르겠던 곳 — 자유
- E2. 버그 · 튕김 · 발열 · 배터리 문제 — 자유(가능하면 스크린샷)

**F. 자유 의견**
- F1. 하고 싶은 말
- F2. **[플레이 기록] 붙여 넣기**

## 기록 읽는 법

설정 → [플레이 기록] 요약의 줄:
- `총 플레이 · 접속 · 한 번에 평균` — 세션 길이(방치형은 짧고 자주가 정상)
- `Lv10 0시간 12분 · Lv20 …` — 누적 플레이 시간 기준 레벨 도달 시각(진행 속도의 핵심)
- `스테이지 N곳 돌파(마지막 …) · 보스 실패 · 쓰러짐` / `가장 막힌 곳` — 난이도 벽
- `광고 · 유물 소환 · 구매(테스트)` — BM 반응(테스트 빌드의 구매는 모의라 실제 결제가 아니다)
- 최근 기록 15줄 — 마지막 행동

원본은 기기의 `playtest_log.txt`(앱 데이터 폴더, 512KB 넘으면 앞 절반을 버림). 사건 이름: session_start/pause/resume/end,
level, stage_clear, boss_fail, death, quest, ad, summon, iap, auto_unlock. 코드: `Utils/PlaytestLog.cs`(ADR0046).
