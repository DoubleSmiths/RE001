[배경]
 1) TravelConditionData가 0행 + 평가 코드도 없어, 여정의 모든 지역
    (산들바람 숲/속삭이는 동굴/무너진 성소)이 처음부터 전부 노출됨.
    기획서 p1-s47(해금 안 된 장소는 표시되지 않음) 미구현 상태였음.
 2) LevelData가 미작성·미로드 상태라 요구 경험치가 코드 폴백
    (100×1.2^(lv-1))으로만 동작.

[설계 결정 — 기획④ 보정]
 통행증은 승급 시 회수·교체되므로(퀘4: 임시→일반, 퀘7: 일반→2급),
 ITEM_REQUIRED(통행증 소지)로 지역을 잠그면 상위 승급 순간 하위 지역이
 다시 잠기는 결함이 있음. → 지역 게이트는 QUEST_CLEAR(승급 보고 퀘
 완료)로 확정. 통행증은 도감·연출용 귀중품 역할.


==================================================================
 1. 코드 변경 (반영 완료)
==================================================================
 - GameManager.cs: IsTravelNodeUnlocked(nodeId) 추가
   · TravelConditionData 조건 AND 평가. 조건 없는 노드 = 항시 해금.
   · 지원 타입: QUEST_CLEAR / BTN_UNLOCKED / ITEM_REQUIRED / LEVEL_REQUIRED
 - UI_TravelPopup.cs: BuildFieldButtons/BuildMapButtons에서 미해금 노드는
   스폰 제외 (기획서 p1-s47 — 숨김 방식)
 - PlayerController.cs: CheckLevelUp의 "_expRequired *= 1.2f" 제거
   · RefreshStats()가 이미 레벨별 요구 경험치를 재설정하는데 또 ×1.2를
     적용해, 세션 내 연속 레벨업(144)과 재접속(120)의 요구치가 달라지던
     기존 버그. LevelData 연결 시 데이터 곡선도 오염시키므로 제거.

==================================================================
 2. 데이터 변경 (반영 완료 / 구글시트 미러 필요)
==================================================================
▶ TravelConditionData.json — 2행 추가:
NodeId	Type	Target	Value	FailMessage
22000	QUEST_CLEAR	7	0	2급 모험가 승급 후 개방됩니다.
23000	QUEST_CLEAR	999	0	아직 개방되지 않은 지역입니다.

 · 21000(산들바람 숲): 조건 없음 = 여정 해금(퀘2)과 동시에 접근 가능.
 · 22000(속삭이는 동굴): 퀘7(2급 승급 보고) 완료 시 노출.
 · 23000(무너진 성소): 999는 "미래 퀘스트" 센티널 — 3급 승급 보고 퀘
   번호가 확정되면 교체할 것.
 · FailMessage는 현재 코드에서 미사용(숨김 방식이므로). 잠김 표시
   UI를 만들 때 사용 예정.
 ★ (2026-07-24 폐기) 구글시트 미러 불필요 — 로컬 엑셀 원천 전환으로
   TravelData.xlsx가 신설되어 위 행이 이미 들어 있음.
   Local_Excel_Pipeline_1.txt 참조.

▶ LevelData.json — 신규 생성 (Lv1~40, 40행):
 · RequiredExp = round(100 × 1.2^(lv-1)) — 기존 코드 폴백과 동일 곡선
   (반올림만 차이). 예: Lv1=100, Lv10=516, Lv20=3,192(계산값 확인),
   Lv40=122,481. Lv41+는 폴백 식이 이어받음.
 · 수치는 성장 커브 확정 작업(기획③ §8-3) 때 이 파일만 고치면 됨.
