# 상업 출시 개발 기준

사용자 요청: 오류를 수정하고 게임이 상업적 수준에 도달할 때까지 개발한다. 재미가 최우선이다.
현재 작업 기준은 Android 세로 화면, 한국어/영어, 오프라인이다. 판매 방식은 사용자 답변 후 확정한다.

## 우선순위와 통과 기준

1. **실행·종료 안정성**: 정상 종료 후 복구창 없이 다시 열림. Package Manager 요청 성공. 반복 팝업 조작에서 소멸 대상 Tween 경고 없음.
2. **첫 플레이**: 새 게임, 정상 속도에서 제작·강화·포획·축성·다음 지역까지 실제 입력으로 완주. 재화 지급·해금·배속 없이 소요 시간, 막힌 지점, 죽음, 반복 행동을 기록한다.
3. **재미**: 첫 포획으로 전투에서 바로 쓸 새 행동을 얻는다. 전투·장비·동행 선택의 효과를 플레이 중 알 수 있다. 의미 있는 선택 사이에 강제 대기나 설명 없는 반복이 생기면 해당 구간부터 개선한다. 구현자의 평가는 별도 기록하고 외부 플레이어 반응으로 대체하지 않는다.
4. **성장·경제**: 다음 목표와 재료 획득처를 UI에서 찾을 수 있고, 제작·강화·축성 전후의 이득이 보인다. 초반 비용과 보상은 정상 속도 실측으로 조정하며 xlsx → JSON 파이프라인을 유지한다.
5. **조작·화면**: 실제 세로 화면에서 터치 영역, 긴 한국어/영어, 겹친 창, 뒤로가기, 결과 연출 중 연타를 검증한다. 잘못된 중복 소비와 입력 막힘이 없어야 한다.
6. **저장**: 구매·제작·성장 결과가 재실행 후 보존되고, 손상/이전 버전 저장을 처리한다. 검증 중 사용자 세이브는 백업하고 복원한다.
7. **기기·성능**: Android 플레이어 빌드와 설치, 백그라운드 복귀, 화면비, 발열·프레임·메모리, 장시간 플레이를 실제 기기에서 측정한다. 연결된 기기가 없으면 미검증 상태를 유지한다.
8. **출시물**: 확정된 플랫폼·판매 방식에 맞춘 앱 식별자, 서명, 권리/라이선스, 스토어 자료와 배포 검증. 사용자 승인 없이 스토어 공개·구매는 하지 않는다.

## 현재 증거와 작업 상태

- 첫 포획 → 동행 능력 대여 → 공명도 100% 영구 습득 구현 및 검증: `5a65da9b`.
- 정상 종료 백업 보관과 일반 재실행 검증: `4974bd37`. 강제 종료의 복구 기능은 유지한다.
- 진행 전체의 기존 실측은 배속 10배를 포함하므로 정상 속도 완주 증거가 아니다.
- 팝업 수명 수정: 같은 프레임 종료 3회·정상 닫기·교체 창 보존 검증 PASS. `docs/decisions/0017-popup-tween-lifetime.md`.
- Package Manager 경로 오류: 실행 환경의 ALLUSERSPROFILE 누락 보완 후 목록·설정 200, 컴파일 오류 0. `docs/decisions/0018-unity-launch-environment.md`.
- 첫 협회 방문의 [임무]도 [대화]와 같은 첫 임무 안내로 연결했다. 변경 전 잡담으로 진입하는 실패를 재현했고, 두 경로의 전체 대사와 완료 콜백·대사 종료 전 진행도 보존 검사 통과. `docs/decisions/0019-first-guild-mission-entry.md`.
- 첫 지역 4종 모두 동행 즉시 수동 능력을 제공한다. 기존 6001/6002 패시브는 보존했다. xlsx → ParseAllLocal → JSON, 503종 데이터 검증, 실제 회복·공격속도 변화·교체 공유 재사용 시간·해제 시 패시브/버프 제거 검사 통과. 포획 화면의 능력 이름도 능력 목록과 통일했다. `docs/decisions/0020-all-starter-companions-active.md`.
- 대화 팝업 즉시 종료 시 파괴된 이미지 접근과 늦은 콜백 실행, 긴 줄 스킵 직후 짧은 줄 시작 시 배열 범위 오류를 각각 재현했다. Tween 수명 지정과 줄별 배열 캡처 후 즉시 종료·정상 오프닝·연속 스킵 3회·화살표 시작/정지 검증 통과. 오류/경고 콘솔 0건.
- 이번 정상 속도 검증은 새 게임 → 첫 임무 → 첫 필드 → 2001 첫 포획·동행 → 귀환 → 협회 보고·연금공방 해금까지 진행했다. 배속과 재화/해금 지급 없이 UI 레이캐스트를 통과한 입력을 사용했다. 귀환은 실제 게임뷰 연속 클릭으로 확인했다. 도중 코드 수정과 격리 회귀 검증을 했으므로 한 번 관통하는 완주 증거가 아니며, 도구 분석 대기가 전투 시간을 늘려 초반 소요 시간의 근거로도 쓰지 않는다.
- 파싱 후 검증 세이브로 전투에 재진입해 실제 게임뷰의 6001 버튼을 클릭했다. HP 407/410 → 410/410, 재사용 시간 17.6초 확인. 회복량 전체 공식은 별도 격리 검증에서 통과했다.
- 전투 능력 버튼: 준비 상태에도 검은 덮개가 남던 오류를 재현한 뒤 수정했다. 전리품 위 독립 행으로 이동하고 기존 픽셀 프레임·능력 이름·상태를 표시한다. 6개 슬롯의 화면 범위/귀환·여정·하단 탭과 겹침 없음/최상위 레이캐스트, 실제 발동 후 덮개/숫자 중앙, 마을·전투 상태, 팝업 뒤 입력 차단, 한·영 전환 검사 통과. 실제 게임뷰에서 두 번째 능력(6002)을 눌러 가속 발동과 6개 미니몬 능력의 공용 재사용 시간 표시도 확인했다. `docs/decisions/0021-combat-ability-controls.md`.
- 귀환 시 생존 몬스터의 피격 Tween이 남는 SpriteRenderer 경고를 재현했다. 비활성화 때 피격 코루틴·Tween을 종료하고 색을 복원한다. 피격 시작 전/중간/흰색 복귀 중 제거, 비활성·재활성·정상 피격, 무관한 Tween 보존 검사 통과. 수정 후 오류/경고 콘솔 0건.
- 입문 제작: 레벨 5·90골드의 장검/세검과 강화 18행을 추가했다. 기존 31레벨 이후 곡선을 보존하며 공격력과 치명타를 비교할 수 있다. 제작 비용·조건·중복·장착·직렬화 159개 검사, 재료 링크·64개 한영 출처 배치·드래그 이벤트 경로, 숙련도 99/100의 축성 미리보기·명시적 습득 검사 통과. 긴 영문 제목·출처와 숙련도 안내를 정리했다. 상세: `Novice_Growth_Verification_20260910.md`, ADR0022.
- 직업 선택: 강철의 기억을 HP·방어형, 강인함을 HP형으로 같은 기억 비용에서 비교하도록 조정했다. 미적용 ComboKeep를 실제 게이지 감소에 연결하고, 12개 직업 능력의 단계별 효과·조건을 한영으로 표시한다. 스탯·기억·직렬화 14개, 콤보 Tick 30개, 한영 설명/버튼 48뷰 및 축성 입력·닫기 연타 검증 통과. 긴 설명 후 하단 메뉴 겹침도 수정했다. 상세: `Class_Choice_Verification_20260910.md`, ADR0023.
- 마을 화면 교체에서 이전 그룹의 Tween 콜백이 파괴된 UI를 참조하던 경고를 수정했다. 실제 교체 3경로, 정상·연쇄 해금의 콜백 횟수·입력 잠금 복원·무관한 Tween 보존을 검사했고 오류/경고 0건이다. 상세: `Village_Tween_Verification_20260910.md`.
- TitleScene 새 게임에서 배속·지급·플레이 재시작 없이 첫 포획, 장검 제작·강화, 동굴 입구 전투, 첫 축성·기억까지 연속 진행했다. 사망 1회 포함. 도구 대기 때문에 소요 시간은 일반 플레이어 기준이 아니다. 상세: `Continuous_Playthrough_20260910.md`.
- 일반 피격으로 플레이어 본타가 약 5.6초 정체되는 현상을 관측하고, 공격 중 피격 모션 취소와 이전 피격 복귀 코루틴 경합을 수정했다. 실제 AtkSpeed도 공격 주기에 반영했다. 실제 Animator 타격·버프 만료·피격·사망·격리 복원 검사 14/49 실패 → 49/49 통과. 상세: `Player_Attack_Verification_20260910.md`, ADR0024.
- 도감의 미사용 저작 Tween 2,012개를 제거하고 시작 용량 설정 누락을 수정했다. 503칸의 클릭·별·동행 표시, 반복 종료와 무관한 Tween 보존 검사 통과. 첫 프레임 801~843ms → 689~729ms이나 동기 생성과 큰 할당은 남아 있다. 상세: `Bestiary_Performance_Verification_20260910.md`, `857277bc`.
- 해금 안내는 실제 마을 Sprite와 부모 폭 내 줄바꿈을 사용하며 열린 상태의 한영 변경을 지원한다. 실제 5종 해금 콜백 × 2개 언어, 타이핑·스킵·자연 완료·닫기 검사 통과. 상세: `Unlock_Popup_Verification_20260910.md`, `89fd3ab8`.
- 도감 가시 지역 생성: 처음 20칸, 503종 왕복 중 최대 43칸으로 줄였다. 첫 UI 프레임 687~688ms → 95~153ms, 해당 Editor 프레임 GC 최고값 약 53MB → 6MB. 전체 배치·503종 왕복·재생성 후 클릭·동행 변경·한영 전환·반복/즉시 닫기 검사 통과. 상세: `Bestiary_Performance_Verification_20260910.md`, ADR0025.
- 도감·포획 전투 정지: 공격 타격 직전 30초 보존과 재개 29개, 중첩/SoulShop/Clear와 기존 배율 복원, 정지 중 포획 성공·실패의 실제 UI 입력과 연출 검사를 통과했다. 포획 입장 모션을 끄면서 유혹·성공 Tween까지 죽이던 문제도 수정했다. 상세: `Battle_Reading_Pause_Verification_20260910.md`, ADR0026.
- 다음 우선 작업: 축성 목록 가독성과 초반 선택 간격. Android 실기기 터치·완주·장시간 성능·외부 플레이어 재미 평가는 미검증이다.
- 전체 출시 기준은 아직 통과하지 않았다. 각 작업은 컴파일·플레이 실측 후 별도 커밋한다.
