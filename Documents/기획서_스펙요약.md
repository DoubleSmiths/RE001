## 1. 스탯 (p1-14, 15)

기본 14종. 괄호는 초기값.
물리공격력(10) / 마법공격력(10) / 치명타(0.00%) / 치명타피해(150%) / 명중률(80.0%) /
공격속도(100%) / 최대체력 / 방어력(0) / 물리저항(0.00%) / 마법저항(0.00%) / 회피율(0.00%) /
회복력(0.0%) / 성장률(100%) / 획득률(100%)

- 치명타·물리저항·마법저항·회피율은 100% 초과 **표기는 그대로, 적용은 100%까지**
- 방어력은 최종 피해량에서 정액 감소, 결과는 음수가 될 수 없음
- 성장률·획득률은 **플레이어 전용**, 나머지는 몬스터에도 동일 적용
- 피해증폭률은 상태창에 표시하지 않지만 존재 — 방어/저항 적용 **전** 피해량에 곱한다
- 물리공격력·마법공격력·최대체력·방어력 4종만 증가율(+n%)·증폭률(xn) 보유
  **기본 × (증가율+1) × 증폭률 = 최종**. 능력치(근력/체력 등)로 오르는 건 [기본] 쪽

## 2. 아이템 (p1-17~19)

- 분류: **소지품**(물약 제외 재료·사용품) / **장비**(종류·개수 고정, 조건 해금·제작) / **귀중품**(컨텐츠 아이템) / **물약**(종류 고정)
- 아이콘은 전부 상호작용 가능 — 누르면 상세정보 팝업
- 소지품 슬롯은 **무제한(ScrollView)**, 단 **초기 16칸만 사용 가능**하고 나머지는 잠금
  - 사용가능: Glow FFFFFF alpha 40, 상호작용 X
  - 사용중: Glow = 아이템 등급색, 상호작용 O
  - 잠김: Glow 0F0F0F, 자물쇠 FFFFFF alpha 150
- 획득은 좌상단부터 오른쪽 순서

## 3. 퀘스트 (p1-24)

- Main / Sub 두 갈래. 첫 시작 시 Main Quest 번호 1
- **전 퀘스트의 완료조건이 아이템 소지였다면 그 개수를 계속 감시** — 미달하면 그 번호로 되돌아간다
- 느낌표는 현재 퀘스트 번호에 들어있는 UI만 켠다

## 4. 여정 (p1-43~47)

3계층: 대분류(마을/탐험) → 중분류(지역) → 소분류(세부장소)

- 초기엔 대분류만 활성. 계층 열기 Anim = Move 0.3s OutQuad from y −150, [뒤로]는 소→중 순으로 한 번에 한 계층씩 DOPlayBackwards
- **중분류(지역) 해금 = 모험가 등급**
- **소분류(던전) 해금 = 첫 장소는 항상 열려 있고, 2번째부터 특정 몬스터 KillCount**
- 원안: **해금 안 된 곳은 목록에 표시하지 않는다**

> ⚠️ **현재 구현은 원안과 다르다(의도적)**
> 잠긴 곳도 회색 + 해금조건 문구로 **표시하고 클릭만 막는다**.
> 이유: 원안대로 숨기면 레벨 1에서 지역 1개·던전 1개만 보여 "던전이 하나뿐"으로 읽힌다(사용자 지적).
> 또한 현재 해금 조건이 원안의 **등급/KillCount가 아니라 레벨**로 생성돼 있다 —
> 원안대로 되돌리려면 TravelConditionData 148행을 등급·KillCount 기준으로 다시 만들어야 한다. (미착수)
