# 입문 제작·성장 안내 검증

## 변경

- 5레벨·90골드에 제작하는 장검(공격 18)과 세검(공격 15, 치명타 확률 10%)을 추가했다. 첫 숲에서 실제 출현하는 마물의 재료를 사용한다. 각각 기존 강화 규칙으로 +9까지 강화할 수 있다.
- 레벨 순으로 제작 장비를 정렬하고, 재료 이름을 누르면 구체적인 드롭 지역·마물 안내를 연다. 긴 영문 장비 이름과 아이템 출처가 프레임·장식선을 넘지 않도록 정리했다.
- 축성 아이콘은 숙련도를 곧바로 쓰지 않고 효과와 기억 비용을 먼저 보여준다. 상세 창의 축성 버튼으로 습득한다. 처치당 숙련도 +1, 100에서 축성 가능 안내를 한·영으로 표시한다.

## 실측

Unity 6000.3.10f1, Android 대상 에디터 플레이 모드. 사용자 저장을 백업한 후 저장 경로를 비활성화한 격리 데이터에서 검사했다. 현재 검증은 정상 속도 새 게임의 연속 완주가 아니다.

- xlsx → ParseAllLocal → JSON. 장비 60→62, 강화 540→558, 레시피 60→62, 번역 1844→1850. 기존 JSON 행 변경 0건. 생성기 재실행 변경 0건이며 기존 생성기의 추가 행 보존은 임시 복사본에서 검증했다.
- `verify_novice_crafting.cs`: 159개 검사 통과. 4레벨/5레벨 경계, 골드·각 재료 부족 시 전체 데이터 불변, 정확한 소비량, 중복 제작 차단, 실제 장착 공격·치명타 변화, 강화 18행, 직렬화 후 장착 참조 복원.
- `verify_item_links.cs`: 실제 최상위 레이캐스트를 통과한 재료 클릭, 64개 한·영 드롭 출처의 텍스트·장식선 범위, 드롭 없는 아이템의 기존 출처, ScrollRect까지 드래그 이벤트 전달 검사 통과.
- `verify_growth_ui.cs`: 숙련도 99/100에서 실제 아이콘 클릭은 상세 창만 열며 수치·보유 불변. 미보유 효과와 기억 비용 표시, 99에서 축성 비활성, 100에서 상세 버튼 클릭 시 한 번 습득하고 숙련도 0. 열린 축성 창의 한·영 안내와 100/100 게이지 배치 검사 통과.
- 실제 게임뷰 마우스 입력으로 입문 장비 상세, 재료 출처, 첫 축성 능력 미리보기를 열었다. 제작 버튼 클릭 후 골드 913→823, 신규 장검 보유를 확인했다. 긴 영문 무기명은 제목 프레임 안에서 두 줄, 최종 축성 안내는 두 줄로 표시된다.
- 네이티브 마우스 휠 스크롤은 확인했다. 자동화 도구의 네이티브 드래그는 이동 결과를 확인하지 못해 통과로 기록하지 않는다. 프레임을 나눈 Unity 드래그 이벤트 경로는 통과했으며, 실기기 손가락 입력은 별도 검증 대상이다.
- 수정 후 컴파일·플레이 콘솔 오류/경고 0건. 새로운 아이콘은 기존 Addressable 스프라이트를 사용한다.
