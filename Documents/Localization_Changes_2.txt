[배경]
게임은 한/영을 LocalizationData(키→Kor/Eng)로 지원합니다. 그런데 SkillData 등은
텍스트를 직접 박아두고(SkillData는 한글+영문 컬럼 따로) 있었습니다. 이를 키값으로
바꾸고 LocalizationData에서 한/영을 가져오도록 일원화했습니다.

==================================================================
 1. SkillData 시트 구조 변경  ★중요: 구글시트 재생성 필요★
==================================================================
- 영문 컬럼 3개 제거: NameEng, DescEng, StoryEng
- Name / Description / Story 값을 LocalizationData '키'로 변경
  (예: Name = Skill5008NameText). 표시 시 한/영 자동.
- 컬럼 수: 31 → 28
- ⚠️ SkillData 구글시트(RE001_DataSheets)는 컬럼이 바뀌었으므로 반드시 새 구조로
  재생성해야 합니다. 기존(영문 포함) 시트로 ParseExtraDataFromGoogleSheets를
  돌리면 컬럼이 밀려 데이터가 깨집니다. (로컬 ParseExtraData는 이미 일치/검증됨)

==================================================================
 2. EquipmentData / MinMonData 이름 키값화
==================================================================
- EquipmentData.Name: 30001 "여행자의 검" → "Equip30001NameText"
- MinMonData.Name: 2001 → "Minmon2001NameText", 2002 → "Minmon2002NameText"
  (2003 고블린은 1단계에서 GoblinNameText)
- 컬럼 구조는 동일(값만 키). 구글시트는 값만 바꾸면 됩니다.

==================================================================
 4. 코드 변경 (참고)
==================================================================
- SkillData 클래스: NameEng/DescEng/StoryEng 필드 제거
- DataTransformer.ParseSkillDataSheet: 영문 3컬럼 제거 + 인덱스 재매핑(0~27)
- AbilityManager.GetName/GetDesc/GetStory: Util.Localize로 전환(한/영 자동)
- gen_data_sheets.py(xlsx 생성 도구): SkillData 컬럼 정의에서 영문 3개 제거

==================================================================
 5. 미처리 / 확인 필요
==================================================================
- CreatureData.UniqueSkillName/Desc: 현재 값이 "0"(고유기술 미구현 placeholder)이라
  키값화 보류. 고유기술 데이터가 생기면 키값화 필요.
- MinMonData.Name은 현재 화면 표시 사용처가 없어(미니몬 이름은 CreatureData.Name 사용)
  선제 키값화만 해둠.
- 구글시트(SkillData/EquipmentData/MinMonData = RE001_DataSheets) 재생성/갱신 필요.
  원하시면 새 시트 생성 + URL 교체를 진행하겠습니다.
