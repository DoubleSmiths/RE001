# 새 게임 연속 검증 — 2026-09-10

## 조건

Android 타깃 Unity Editor의 TitleScene에서 새 게임을 시작했다.
`Time.timeScale=1`, 치트 비활성, 재화·경험치·아이템·해금 지급 없이 실제 게임뷰 입력과
EventSystem 최상위 레이캐스트를 통과한 클릭을 사용했다. 진행 중 코드/데이터 변경이나
플레이 모드 재시작은 하지 않았다. Android 실기기 검증은 아니다.

별도 읽기 전용 코루틴이 2초마다 진행 상태, 전투 중 0.1초마다 HP·공격 상태·적 상태를 기록한다.
CLI 호출과 분석 때문에 마을 대기와 프레임 지연이 포함되어 총 경과 시간을 일반 플레이어의
첫 플레이 소요 시간이나 기기 성능으로 해석하지 않는다. 사용자의 기존 저장은 별도로 백업했다.

## 확인한 흐름

| 단계 | 관측 |
|---|---|
| 첫 임무 | 타이틀 시작 → 협회 임무 → 안내 대화 → 여정 해금 → 첫 필드 진입 |
| 첫 포획 | 첫 필드 5킬 뒤 슬라임 관심 유지. 마을에서 첫 포획 성공 → 동행 → 수동 회복 버튼 표시 |
| 첫 사망 | 도감을 읽는 동안 전투가 계속되어 고블린에게 사망. 마을로 복귀하고 관심은 유지 |
| 능력 사용 | 실제 게임뷰의 6001 버튼 클릭으로 `Heal 59.4` 발동. 재사용 시간 표시 |
| 성장 선택 | 획득한 능력점수 6점을 체력에 투자, 최대 HP +120 |
| 첫 제작 | 레벨 8, 35킬, 205골드에서 견습생의 장검 제작·장착. 90골드와 표시 재료 소모, 공격력 +18 |
| 첫 강화 전 | 제작 직후 115골드, 강화 비용 120골드로 즉시 연속 강화 불가 |
| 다음 구간 | 여정으로 21020 진입. 다른 몬스터 구성과 재료 확인 |
| 첫 강화 | 41킬·레벨 9에 귀환. 일반 주문서, 성공률 90%에서 +1 성공. 공격력 18→27, 골드 165→45, 젤리 7→4, 주문서 11→10 |
| 수도원 | 48킬·레벨 10에 임무 보고 후 해금. 축성 목록 48/100, 미보유 능력 상세에서 강철의 기억 HP +50·방어 +5 표시 |
| 다음 대지역 | 레벨 13, 91킬에 속삭이는 동굴 입구(21110) 진입. 실제 전투와 회복 능력 사용 확인 |
| 첫 축성 | 레벨 15, 101킬에 수도원 귀환. 숙련도 100을 소비해 연계 감각(5142) 습득 후 기억하기. 숙련도 0, 기억 목록에 5142 포함 |

새 게임 → 포획 → 제작 → 강화 → 다음 대지역 전투 → 축성을 같은 Play 세션에서 완료했다.
03:50 KST에 기록을 보존하고 플레이 모드를 종료했다. 첫 사망 1회가 포함된다.
일반 플레이어의 소요 시간·실기기 통과·상업 출시 완료를 의미하지 않는다.
완주 저장은 로컬 `SaveData.continuous-complete.json`에 보관했다.

## 재미와 조작에서 발견한 문제

- **반복 피격이 플레이어 공격을 끊는다.** 고블린 전투에서 게임 시간 618.687초 본타 이후
  624.292초까지 약 5.6초간 다음 본타가 나오지 않았다. 중간 적 HP 감소는 동행의 1 피해였다.
  공격 시작 후 0.21~0.32초에 피격 모션이 들어와 0.5초 타격 이벤트를 취소했다.
  몬스터는 공격 중 피격 모션을 억제하므로 같은 위험을 부담하지 않는다.
- **능력 공격속도가 공격 주기에서 누락된다.** `AutoAttack`은 콤보와 물약만 가산하고
  실제 `AtkSpeed`를 사용하지 않는다. 공속 능력의 수치 변화만으로 체감 개선을 주장할 수 없다.
- **첫 보상을 읽는 동안 사망한다.** 도감·포획 모달 뒤에서도 전투가 진행되고 수동 능력은 가려진다.
  첫 포획 연출은 입장만 최소 4.2초여서 전투 중 읽기와 생존이 충돌한다.
- **수도원 해금과 첫 선택 사이에 추가 사냥이 필요하다.** 해금 시 48/100.
  목록은 큰 잠금 아이콘으로 덮이고 이름이 없어 비교를 위해 각각 열어야 한다.
- **임무 지역명이 실제 수집 경로와 맞지 않는다.** '속삭이는 동굴 조사'는 첫 숲에서 얻은
  슬라임 젤리로 보고됐다. '폐허가 된 성소 조사'도 숲 두 번째 구간의 독버섯 갓으로 완료됐다.
- **해금 안내 품질**: 상점 아이콘이 흰 사각형으로 보였고 수도원 설명은 세로 게임뷰 좌우를 넘었다.
- **도감 비용**: 첫 열기에서 Tween 용량 경고 3회, 강화 연출에서 Sequence 용량 경고 1회.
  도감은 503개 박스의 사용하지 않는 저작 Tween 약 2012개를 생성한다. 프레임/메모리 실측은 후속이다.

이 평가는 구현자의 직접 관찰이다. 외부 플레이어가 재미있다고 느끼는지 확인한 증거는 아니다.

## 로그 구분

로컬 증거는 무시된 `Documents/Verification-20260909-Gameplay/commercial-20260910/`의
`continuous-1x.jsonl`, `continuous-combat.jsonl`에 있다. 콘솔에는 검증 클릭 도구의
잘못된 버튼 이름·가려진 배경·대화 대기 초과 오류가 섞였다. 이 오류는 게임의 런타임 결함과
구분한다. 경고를 지우거나 전체 콘솔을 오류 0건으로 표현하지 않는다.
직업 목록 복제 슬롯들은 같은 내부 버튼 이름을 갖는다. 이름만 지정한 클릭 도구가
이전에 미리 본 강철의 기억 대신 연계 감각 슬롯을 열었으므로, 습득 결과는 5142로 기록했다.
반복 검증에서는 슬롯 부모나 실제 화면 좌표로 대상을 구별해야 한다.
