# 직업 능력 선택·설명 검증

## 변경

- 강철의 기억(5004): 기억 4 → 2, 최대 HP +50 유지, 방어력 +5 추가. 강인함(5125)의 HP +120·기억 2와 방어/체력을 비교한다. 수치는 단계에 비례한다.
- 연계 감각(5142): 사용되지 않던 ComboKeep를 콤보 감소 속도에 연결했다. 10%는 1.1배, 40%는 1.4배 유지한다. 타격 충전량과 기억/망각 순간의 현재 게이지는 보존한다.
- 직업 능력 12개의 습득·현재·다음 단계 본문을 실제 데이터와 한영 템플릿으로 생성한다. 확률·시간·효과 배율·다중 스탯을 구분한다. 치명 피해 직전 회복을 무조건 생존으로, 확정 포획 실패 임계값을 최소 시도 횟수로 설명하지 않는다.
- 긴 다음 단계 설명을 펼친 뒤 기억 버튼·게이지가 하단 메뉴와 겹치는 문제를 재현했다. 내용 갱신 후 전체 창의 중앙 위치를 다시 계산한다. 코드 진입 이동으로 대체된 프리팹 Tween은 자동 생성과 기존 Tween도 종료한다.

## 데이터 파이프라인

`python _tools/upgrade_class_choices.py --apply` → Unity `Tools/ParseAllLocal (로컬 전체 파싱)`.

재실행 변경 0셀. SkillData는 572행 유지, 5004의 MemoryCapacity·StatTypes·StatBonuses 세 필드만 변경했다. LocalizationData는 기존 22행의 번역·설명 수정과 템플릿 27행 추가로 1850 → 1877행이다. 기존 저장의 습득·기억·단계 ID는 변경하지 않는다.

## 플레이 모드 검증

Unity 6000.3.10f1, Android 대상 에디터 GameView. 사용자 저장 경로를 비활성화한 격리 데이터에서 실행했다.

- `verify_combo_keep.cs`: 수정 전 API 누락 RED, 수정 후 30개 검사 PASS. 0/10/40% 실제 Tick 감소, 충전량·최대값·중복 프레임 방지, 기억·망각·단계 변경, 만료를 포함한다.
- `verify_class_choices.cs`: 변경 전 기억 4/2 비교 RED, 변경 후 14개 검사 PASS. 다중 스탯 우선 적용, 단계 5 중복 HP 없음, 기억 비용 반환, 직렬화 왕복을 포함한다.
- 동일 난수의 BattleMath.Resolve: 기본 HP180/방어4, 공격20/70. 강철은 HP230·피해10/53, 강인함은 HP300·피해14/57. 약한 반복 타격에서는 방어, 큰 타격에서는 체력의 버틸 수 있는 피해 횟수가 유리했다. 실제 사망까지의 전투나 외부 재미 평가를 대체하지 않는다.
- `verify_class_descriptions.cs`: 한영 × 12개 × 습득/다음 단계 48뷰 PASS. 실제 glyph의 장식 패널·화면 경계, 버튼과 본문 겹침, 하단 메뉴와 행동 버튼·기억력 표시 겹침을 검사한다. 진입 이동 0.5초가 끝난 최종 배치를 측정한다.
- `verify_skill_detail_close.cs`: 닫기 시작 직후 단계 미리보기·습득 후 갱신을 호출한다. 위치 보정이 닫기 Tween을 취소하던 RED를 확인했고, 닫기 가드 후 두 경로 모두 정상 종료 PASS.
- `verify_growth_ui.cs`: 숙련도 99/100 실제 아이콘 레이캐스트가 미리보기를 열고 숙련도를 소비하지 않음, 효과·기억 비용 표시, 상세 버튼으로 100에서 한 번만 습득, 한영 숙련도 안내 배치 PASS.

실제 Windows GameView에서 영어 그림자 걸음의 다음 단계 버튼을 클릭해 현재 회피 +18%p와 다음 +36%p, 고정 지속시간 10초를 확인했다. 실기기 터치·일반 속도 연속 완주·장시간 밸런스·외부 플레이어 재미 평가는 아직 미검증이다.

수정 후 실제 클릭 화면에서 기억 버튼·게이지가 하단 메뉴 위로 분리된 것을 확인했다. 마지막 컴파일 오류 0. 격리 마을 재생성에서 별도의 UI_Village1BtnGroup Tween 경고가 드러나 후속 수명 수정으로 분리했다. 영어 직업명 영역의 고정 한국어와 역할 라벨/아이콘 가독성은 추가 화면 정리 항목이다.
