# 기능 해금 안내 검증

## 수정

상점 아이콘의 리소스 이름과 실제 서브스프라이트 이름이 달라 해금 안내에 흰 사각형이 표시됐다. 마을의 다섯 해금 콜백이 버튼에 이미 로드된 Sprite를 전달하도록 바꿨다. 기존 문자열 SetInfo 호출도 유지한다.

본문은 부모 폭 안에서 줄바꿈하고 세로 높이를 내용에 맞춘다. 한국어/영어 UI 폰트를 적용하며, 열린 상태에서 언어를 바꿔도 제목과 본문을 함께 갱신한다. 진행 중인 타이핑은 새 문장으로 다시 시작하고, 읽기를 마친 문장은 즉시 표시한다. 이전 타이핑의 Tween과 코루틴을 종료하고 문장별 알파 배열을 분리했다.

## 검증

Unity 6000.3.10f1 Play, 마을의 실제 `TryPlayUnlockAnim` 콜백으로 상점·수도원·여정·대장간·연금공방을 각각 한국어/영어로 열었다. `_tools/verify_unlock_popup.cs`가 복제 GameData와 격리된 저장 경로에서 실행 후 원래 데이터·언어·장착 상태·경로를 복원한다.

- 변경 전 아이콘·글리프 경계·언어 전환 검사 104건 실패를 재현했다.
- 변경 후 5종 × 2개 언어 모두 통과했다. 아이콘 일치, 전체 글리프의 Content/화면 경계, TMP overflow 없음, 입력 잠금 해제, 타이핑 도중 언어 변경, 클릭 스킵, 자연 완료, 완료 후 언어 변경, 닫기 이벤트 1회와 스택 정리를 검사했다.
- 검증 구간 오류/경고 0건. 변경 전 로그의 외부 Curl 연결 오류는 UI 실패와 분리했다.
- 컴파일 후 오류 콘솔 0건 확인. 읽기 전용 리뷰에서 변경 범위의 결함은 발견되지 않았다.
- 실제 게임뷰에서 수도원 안내 아이콘과 한국어 4줄 본문이 겹침 없이 보이는 것을 확인했다.

로컬 원본 로그: `Verification-20260909-Gameplay/commercial-20260910/editor-unlock-red.log`, `editor-unlock-green.log`. Android 실제 화면 검증은 아직 수행하지 않았다.
