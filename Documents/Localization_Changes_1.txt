 데이터/로컬라이즈 변경 정리 #1 — 고블린 인게임 정상화 + 몬스터 이름 키값화
 작성일: 2026-06-21
 대상: 기획자 (구글시트 반영 필요)
==================================================================

[배경]
산들바람 숲에 고블린을 추가하면서 ① 도감 아이콘이 번호별로 안 나오고
② 잡기 팝업에 슬라임 이미지가 뜨고 잡기 실패 시 시도횟수가 안 늘고
③ 이름이 "1"/"Goblin"으로 노출되던 문제를 수정했습니다.
모든 표시 텍스트는 LocalizationData(키→한/영)에서 가져오도록 바꿉니다.


==================================================================
 1. LocalizationData 시트에 행 추가  ★구글시트 반영 필요★
==================================================================
※ Localization 구글시트
  (https://docs.google.com/spreadsheets/d/1ydclXzn6lWwzlzMNw9lBOPUSDeg4Ats2)
  에 아래 행을 추가한 뒤 Tools > 파싱(GS_ParseLocalizationData) 실행하세요.
※ 컬럼: TextKey / Kor / Eng

  키 SlimeNameText,      Kor 슬라임,        Eng SLIME
  키 RabiSlimeNameText,  Kor 라비 슬라임,    Eng RABI SLIME
  키 GoblinNameText,     Kor 고블린,        Eng GOBLIN
  키 BeastiaryText,      Kor 마물 도감,      Eng BESTIARY
     └ 도감 팝업 타이틀이 "BeastiaryText"로 그대로 노출되던 버그도 수정(키 누락이었음).

⚠️ 현재는 게임 JSON(LocalizationData.json)에 직접 넣어 동작시켜 둔 상태입니다.
   구글시트에 위 행을 넣지 않고 재파싱하면 JSON이 덮어써져 사라집니다. 꼭 반영하세요.


==================================================================
 2. CreatureData 변경  (몬스터 이름 키값화 + 아이콘 정정)
==================================================================
※ Creature 구글시트(GSHEET_CREATURE)도 동일하게 반영 필요.
  (현재 CreatureData.json은 직접 수정해 둠 — 재파싱 시 덮어쓰기 주의)

  - 2001 슬라임:  Name "1"  → "SlimeNameText"      / IconLabel "Slime"  → "slime_monster_0"
  - 2002 라비:    Name "2"  → "RabiSlimeNameText"  / IconLabel "RabiSlime" → "slime_monster_0"(임시)
  - 2003 고블린:  Name "Goblin" → "GoblinNameText" / IconLabel "goblin_monster_0"(유지)

  · Name은 이제 LocalizationData 키입니다(화면 표시 시 한/영 자동 전환).
  · IconLabel은 도감/잡기/상세 아이콘에 쓰는 스프라이트 주소입니다.


==================================================================
 3. MinMonData 변경  (고블린 미니몬 추가)
==================================================================
  - 신규 2003 고블린 미니몬 추가:
      Name=GoblinNameText, IconLabel=goblin_monster_0, PrefabLabel=Monster,
      PetAnimLabel=Goblin(동행 시 고블린 애니), MonsterDataId=2003,
      MaxTameCount=10, CatchChance=0.1, 등급 E, 기본 공격 8.
  · 이게 없어서 고블린 잡기 시 이미지/시도횟수/포획이 전혀 동작하지 않았습니다.


==================================================================
 4. 코드/도감 변경 (참고 — 기획 입력 불필요)
==================================================================
  - 도감 목록(REGION_STUB): 산들바람 숲에 고블린(2003) 추가 → 도감에 003 슬롯 노출.
  - 스프라이트 Addressable 등록: slime_monster.png / goblin_monster.png 의
    대표 프레임(_0)을 PreLoad 등록(주소 slime_monster_0.sprite / goblin_monster_0.sprite).
  - 이름 표시처 3곳을 Util.Localize로 통일(미니몬 기록창/나의 미니몬창/잡기 대사).


==================================================================
 5. 기획자 확인/추가 작업 필요 항목
==================================================================
  (1) ★라비 슬라임(002) 전용 아이콘 에셋이 없습니다.★
      현재 임시로 슬라임과 같은 아이콘(slime_monster_0)을 씁니다.
      → 라비 전용 아이콘 이미지를 추가해 주시면 IconLabel을 교체하겠습니다.
  (2) 위 1~3의 구글시트 반영(행 추가/값 수정) 후 재파싱 1회 필요.
  (3) 고블린 스탯/잡기확률(MaxTameCount 10, CatchChance 0.1)은 임시값 — 밸런스 조정 가능.


==================================================================
 [검증 완료] (2026-06-21, PlayMode)
==================================================================
  - 이름: 2001→슬라임 / 2002→라비 슬라임 / 2003→고블린 (영문 모드 SLIME/RABI SLIME/GOBLIN)
  - 아이콘 Load: 셋 다 OK(002는 슬라임 임시). 도감에 001/002/003 슬롯 노출.
  - 잡기: 고블린 팝업 이미지=goblin_monster_0, 이름=고블린. 실패 3회 시 시도횟수 0→3 정상 누적.
