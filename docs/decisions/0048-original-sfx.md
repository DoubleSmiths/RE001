- 상태: 채택
- 날짜: 2026-09-30

## 맥락

출시 권리 점검(`Documents/Store/Third_Party_Notices.md`, 2026-09-29): 효과음 57개 중 5개는 상용 라이브러리
(SmartSound FX "MONSTERS" 2개 — 몬스터 503종 전부의 피격·사망음, Evil Mind "Medieval Fantasy Audio Bundle" 3개)라 구매 영수증
확인이 필요했고, 51개는 메타데이터가 없어 출처를 몰랐다. 모두 2026-03-06 첫 커밋으로 한꺼번에 들어왔다. 상업 출시의 가장 큰 권리 위험이었다.
배경음악은 이미 자작(`gen_bgm_suite.py`·`gen_chiptune.py`, 포획음 `SFX_MinimonCaught` 포함)이다. 사용자 결정(2026-09-30): 효과음 자작음 교체.

## 결정

- **`_tools/gen_sfx.py`** — 효과음마다 짧은 조리법 함수 하나(시드 고정, 같은 결과). `gen_chiptune` 의 도구(BLEP 펄스 · NES 삼각파 · FIR 저역 통과 ·
  아르페지오)를 그대로 써서 배경음악과 같은 8/16비트 소리. 새로 더한 것: 휘몰아치는 1비트 잡음(휘두르기·바람), 대역 필터, 금속음
  (살짝 어긋난 펄스 두 개 + 링 변조 삼각파). 높은 음(종·거품·휘파람)은 대역 제한 삼각파(NES 삼각파는 고음에서 계단 잡음).
- **파일 이름·폴더·확장자 그대로 덮어쓴다** — .meta GUID·어드레서블 주소 불변. `.wav` 는 16비트 모노 44.1kHz, `.mp3` 는 ffmpeg libmp3lame
  128kbps 모노. `SFX_MinimonCaught` 와 배경음악은 건드리지 않는다.
- **음량** — 가장 큰 200ms 구간 기준(전체 평균이면 울리는 금속음이 10dB 작게 잡힌다): UI -18, 타격 -14, 짧은 곡 -16 dBFS, 피크 -1dBFS 상한,
  줄이기만 한다. 앞뒤 3~5ms 페이드, 뒤 무음 자르기.
- **길이** — 원래 길이 근처, 긴 것은 줄였다(성공 팡파르 5.9s → 1.6~3.3s, 새 기능 8.5s → 3.3s). 매번 나는 소리는 짧게(베기 0.65 → 0.33s,
  몬스터 피격 0.23s). 대장간 망치는 연출 흔들림(0.25s)에 금속음이 맞고 한 번 치고 튕기는 소리(한 의식에 세 번 난다).
