# 0022. 초반 제작 선택과 성장 안내

- 상태: 채택
- 날짜: 2026-09-10

## 맥락

시작 장비 6종은 모두 지급되며 보유 장비는 다시 제작할 수 없다. 기존 다음 제작 레벨은 31이어서 대장간을 해금해도 초반 제작 목표가 비어 있었다. 아이템 설명의 획득 장소는 넓은 지역 이름만 표시했고, 축성 창은 숙련도 수치만 보여주었다.

## 결정

기존 60종과 31레벨 이후 곡선은 유지하고, 레벨 5·90골드의 입문 무기 2종을 추가한다. 장검은 공격력 18, 세검은 공격력 15와 치명타 확률 10%를 제공한다. 같은 무기 슬롯을 사용하므로 한 번에 하나를 장착한다. 재료는 첫 숲에서 실제 출현하는 마물 2001·2002·2003·2101의 드롭만 사용한다. 장검은 젤리 계열, 세검은 고블린의 드롭도 요구한다. 강화는 기존 비용·성공률·내구도 규칙을 그대로 사용하고, 무기별 9단계 보너스와 필요 재료를 시트에 추가한다.

장비 목록은 제작 요구 레벨 후 DataId 순으로 정렬한다. 제작 본문의 재료 이름을 눌러 기존 아이템 상세 창을 열며, 드롭 마물의 서식지와 여정 노드를 연결해 구체적인 획득 장소를 표시한다. 축성 창의 중복 제목은 숙련도 획득·사용 방법 안내로 바꾼다.

축성의 미보유 능력 아이콘은 숙련도를 즉시 소비하던 동작을 없애고, 보유 여부·숙련도와 관계없이 기존 능력 상세 창을 연다. 효과를 확인한 뒤 상세 창의 축성 버튼으로 습득한다. 이를 통해 첫 능력을 설명 없이 선택하거나 숙련도가 부족하다는 이유로 효과를 보지 못하는 상황을 없앤다.

## 결과

장비·레시피·강화·번역의 원천은 xlsx이며 `upgrade_novice_crafting.py`로 재현한다. 기본 생성기를 다시 실행해도 생성 범위 밖의 추가 장비 레시피·강화 행을 보존해야 한다. 기존 저장 구조와 장비 ID는 바꾸지 않는다.

공격력과 치명타 선택은 초반 전투에서 비교할 수 있는 출발점이다. 최적 밸런스나 재미가 입증됐다는 뜻은 아니며, 새 게임 정상 속도 완주와 외부 플레이 평가로 가격·수치·획득 시간을 계속 조정한다. 모바일 화면에서 본문 스크롤과 재료 링크 입력을 함께 검증한다.
