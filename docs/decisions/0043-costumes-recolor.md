# 0043. 의상(치장) — 주인공 그림 재채색 8벌, 능력치 없음

- 상태: 채택
- 날짜: 2026-09-30

## 맥락

사용자 결정(2026-09-30): "의상 치장은 좋은 내용이니 수용한다". 앞서 의상은 "캐릭터 그림을 새로 그려야 한다"며 남겨 뒀다.
주인공 애니메이션은 시트 7장(대기·달리기·공격 둘·피격·쓰러짐 — Player_01/02)이고, 동작마다 새 옷을 그리면 칸 수·타이밍을
전부 다시 맞춰야 한다. 설계서 5장 BM 표는 치장을 **능력치 없음(포스트나이트2식)** 으로 정했고, 칭호(ADR0040)도 같은 원칙이다.

실측: 시트 색 2,150가지 중 옷은 두 무리로 갈린다 — 가죽·천(채도 0.33 이상, 붉은 기는 어두운 것만) / 흰 셔츠·머리·강철
(채도 0.15 미만). 살갗은 채도 0.16~0.49 의 밝은 붉은 기라 두 무리 어디에도 들지 않는다. 시트는 읽기 불가(임포트 설정).

## 결정

- **새 그림 대신 부위별 재채색.** 한 벌 = 가죽·천의 색상 이동·채도·밝기 배수 + 흰 옷·머리·강철에 곱할 색(`CostumeData`,
  `_tools/gen_costumes.py`). 경계값은 `Define.COSTUME_*`. 얼굴·바지·외곽선은 그대로 — 파이썬 시안으로 8벌을 먼저 보고 정했다.
- **런타임에 칠한다.** 원본 시트를 GPU 로 복사해 읽고(`Graphics.Blit` + `ReadPixels`) 새 텍스처로 칠한 뒤 원본과 같은 칸·피벗·PPU·
  외곽 메시(`OverrideGeometry`)로 사본 스프라이트를 만든다. `PlayerController.LateUpdate` 가 애니메이터가 끼운 원본을 사본으로 바꾼다.
  시트는 처음 보일 때 한 장씩(에디터 2~5ms), 의상을 바꾸면 버린다. 셰이더(URP 2D Lit 복제)나 임포트 설정(Read/Write) 변경은 하지 않는다.
- **8벌**: 떠돌이 모험가(기본) · 진홍 기사(크리스탈 300) · 숲의 수호자(Lv 50) · 서리 방랑자(450) · 밤의 추적자(시련 3단계) ·
  벚꽃 검사(600) · 황금 영웅(900) · 심연 순례자(심연 30층). 크리스탈 값은 치장 가격대(₩3,300~₩9,900).
- **능력치는 없다.** 한때 가진 의상마다 공격·체력 %를 쌓았으나(슬레이어 키우기식) 설계서의 치장 원칙·칭호와 어긋나 뺐다 — 돈으로 힘을 사지 않는다.
- 입는 곳은 미션 창 11번째 탭 **의상**(탭 줄 6개씩 두 줄). 줄 아이콘은 HUD 초상화를 그 의상 색으로 칠한 것, HUD 초상화도 입은 색.
  크리스탈 의상은 한 번 누르면 '다시 눌러 구매', 두 번째에 산다(사면 바로 입는다). 달성 의상은 레벨업·시련 통과(`RefreshStats`)와
  심연 층 넘김에서 `CheckNew` 가 한 번씩 알린다. 세이브 `GameData.Costumes`(산 것 + 알린 것) · `CostumeId`.

## 결과

- 실측: 진홍 기사 구매 → 크리스탈 −300, 대기·달리기·공격 시트 모두 사본(원본 프레임 0), 발밑 바운즈 차이 0, 공격력·체력 변화 없음 /
  시련 3단계 → '새 의상: 밤의 추적자!' 알림 / 세이브 `Costumes:[2,5]`, `CostumeId:5` / 기본으로 돌리면 원본 스프라이트.
- ⚠️ `Managers.Data.CostumeDic` 은 씬마다 다시 만들어질 수 있다(GameScene 이 에디터에서 `Data.Init` 을 한 번 더). 목록 캐시는 사전
  인스턴스로 갱신하고, 입은 의상 비교는 번호로 한다 — 참조로 비교하다 구매 직후 '착용 중'이 사라졌었다.
- 새 옷 그림이 생기면 `CostumeData` 에 애니메이터·시트 열을 더해 재채색 대신 쓰면 된다(지금은 필요 없다).
