# 0037. 시련(승급 시험)·심연 — 레벨로 여는 영구 배수, 모든 스테이지 뒤의 끝없는 층

- 상태: 채택
- 날짜: 2026-09-30

## 맥락

설계서 4.11(P3 엔드게임): 슬레이어 키우기의 승급(보스 시험을 통과하면 공격·체력 영구 배수)과 끝없는 층.
원안은 "모험가 등급마다 보스 시험, ×1.2씩", "모든 지역 돌파 후 층마다 1.08배, 10층마다 보스, 최고 기록".
이미 있는 것: 스테이지 125곳(스테이지마다 여정 레벨 조건 1~298), 스테이지 보스(`SpawnStageBoss` — 노드 몬스터 가중 평균 × 배수),
보스전 루프(제한 시간·보스 곡·HP 바), 요일 던전의 '입장 예약 → 새 전투 그룹이 시작' 흐름(ADR0034), 미션 창 던전 탭.
그리고 퀘스트 쪽에 이미 **'N급 모험가 승급'**(접수원이 진행하는 등급, `AdventurerRank`)이 있다.

## 결정

- **이름은 '시련'**. 퀘스트의 'N급 모험가 승급'과 같은 말을 쓰면 둘이 같은 것처럼 보인다. 코드 이름은 `PromotionManager`(승급 시험) 그대로.
- **시련은 레벨로 연다**: N단계 = 레벨 `PROMO_LEVEL_STEP`(30) × N, 최대 `PROMO_MAX_TIER`(10) — 300레벨 곡선에 맞춘다.
  원안의 '모험가 등급마다'는 퀘스트 진행에 묶여 몇 단계뿐이고 이야기 흐름을 건드려서 뺐다.
- **배수는 단계당 ×1.1**(공격·마법공격·최대 체력, 단계만큼 거듭제곱 — 10단계 ×2.59). 원안 ×1.2 는 10단계 ×6.19 로,
  레벨 1→300 전체 성장(물공 약 9배)을 덮어 버린다. `RefreshStats` 가 훈련·유물·호감도 다음에 곱한다(`ApplyTo`).
- **시험관 = 요구 레벨 스테이지의 보스 × `PROMO_BOSS_MULT`(1.5)**, 제한 `PROMO_TIME_LIMIT`(45초). 요구 레벨 이하 레벨 조건을 가진
  마지막 스테이지(`GameManager.StageForLevel`)의 보스라, 1단계는 3-3 보스(HP 6,480). 처음엔 사냥하던 스테이지의 보스를 썼는데
  쉬운 1-1 에서 치르면 시험이 형식이 됐다(실측: Lv42 가 2초). **싸우는 곳은 사냥하던 스테이지 그대로**(잠긴 곳으로 데려가지 않는다).
  통과: 단계 +1, 크리스탈 `PROMO_CRYSTAL`(50) × 새 단계. 실패(시간 초과·쓰러짐·귀환)는 벌 없이 곧바로 다시.
- **심연은 모든 스테이지 돌파 뒤**(`AllStagesCleared` — 여정 잠금이 레벨·퀘스트라 건너뛴 스테이지가 있을 수 있어 개수가 아니라 전부 확인).
  마지막 스테이지(25-5) 몬스터를 `ABYSS_START_MULT`(1.2) × `ABYSS_FLOOR_MULT`(1.08)^(층−1) 배로 키워 층마다 `ABYSS_KILLS_PER_FLOOR`(5)마리,
  `ABYSS_BOSS_EVERY`(10)층마다 보스(× `ABYSS_BOSS_MULT` 1.5, `ABYSS_BOSS_TIME` 30초). 능력치와 처치 보상(골드·경험치)이 같은 배수로 커진다
  (`MonsterController.ScaleStats` — 방어만 √배수: 피해에서 그대로 빼는 값이라 같은 배수면 깊은 층에서 '피해 1' 벽이 된다.
  처치 골드는 int 넘침 상한). 처음 넘긴 층마다 크리스탈 `ABYSS_CRYSTAL_PER_FLOOR`(5), 보스 층은 × `ABYSS_BOSS_CRYSTAL_MULT`(5).
  쓰러지거나 보스를 놓치거나 귀환하면 끝 — '몇 층에서 멈췄다 · 최고 · 이번 크리스탈' 한 줄. 끝나면 마지막 스테이지에서 사냥을 이어 간다.
- **입구는 미션 창 던전 탭**(요일 던전 아래 시련·심연 줄). 전투 도전끼리 한곳에 — 창 제목은 '요일 던전' → '던전'.
  시련을 도전할 수 있으면(예약·진행 중이 아니면) 던전 탭과 HUD 미션 버튼에 알림 점(`IsChallengeReady`).
- **흐름은 요일 던전과 같다**: `TryEnter`(예약) → 창 닫고 `EnterAreaWithFade(Battle)` → 새 전투 그룹의 `StartBattle` 이 시련 → 심연 → 던전 순으로
  예약을 확인해 `CoPromotion`/`CoAbyss`/`CoDungeon`, 없으면 사냥. 옛 그룹의 `EndBattle` 은 실행 중인 판만 끝낸다(예약은 건드리지 않는다).
  셋은 한꺼번에 예약되지 않는다(서로의 `TryEnter` 가 막는다).
- **보스 한 판은 공용** `CoFightBoss`(스테이지 보스·시련·심연 보스): 알림·보스 곡·체력 채움·HP 바·맞붙은 뒤부터 재는 제한 시간·지면 물러남.
  결과는 `_bossKilled`/`_bossPlayerDown` 필드(코루틴은 값을 돌려주지 못한다).
- 세이브: `GameData.PromotionTier`, `GameData.AbyssBest`(음수는 로드 때 0, 단계는 읽을 때 `MaxTier` 로 자른다).

## 결과

- 시련 1단계 실측: 3-3 보스 ×1.5(HP 6,480·공격 104), Lv42 통과 5초 / 공격 0.001배로는 시간 안에 못 잡고 쓰러짐 → 단계 그대로.
  통과 후 공격 1174 → 1291, 체력 6010 → 6611(×1.1), 크리스탈 +50.
- 심연 실측(강제 해금): 1→11층, 층마다 5마리, 10층 보스 HP 52만(30초), 처음 넘긴 층 +5 · 보스 층 +25 → 합계 +70, 최고 10층 저장,
  쓰러진 뒤 마을 귀환과 결과 알림.
- 요구 레벨 스테이지를 고르는 데 여정 조건(`LEVEL_REQUIRED`)을 읽는다 — 스테이지 레벨 조건을 바꾸면 시험관도 따라 바뀐다.
- 층 배수는 끝이 없다(100층 ×2,600). 기록 경쟁은 최고 층뿐이고 순위표는 서버가 필요해 두지 않았다.
- 예약이 소비되지 않는 경우(`StartBattle` 전에 전환이 실패)는 요일 던전과 같은 구조라 그대로 둔다 — 입장은 `CanEnterAreaTransition` 을
  먼저 확인하고, 전환은 `PlayEnterAnimation` 까지 다른 전환을 막는다. 생기면 비전투 구역 진입 때 시련·심연 예약을 푼다(던전은 환불 규칙이 필요).
