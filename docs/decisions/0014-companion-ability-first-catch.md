# 0014. 첫 포획을 전투 선택으로 연결한다

- 상태: 채택
- 날짜: 2026-09-09

## 맥락

사용자가 게임성이 약하다는 평가에 대해 개선 실행을 요청했다. 실제 데이터 검사에서 미니몬 503종 중 501종은 creatureId+4000 능력 데이터가 없어 공명도 100% 보상이 지급되지 않았다. 첫 지역의 기존 두 슬라임은 관심 15%와 포획 8~10%가 겹쳐 첫 동행까지 기다림이 길다. 포획 결과창은 동행 버튼도 숨겼다.

## 결정

- 기존 71개 능력은 보존하고 누락된 501종에 실제 고유능력 데이터를 추가한다. 기존 몬스터 성격에 맞는 7개 효과 유형을 공유하며 501개의 서로 다른 전투 메커니즘을 의미하지 않는다.
- 소유한 현재 동행의 고유능력은 기억력 점유 없이 즉시 사용한다. 첫 포획 자체는 영구 습득이 아니다. 공명도 100%에서 영구 습득하고 동행 외 능력은 기존 기억/망각 규칙을 따른다. 이미 기억한 능력은 동행 선택으로 자동 해제하거나 점유 환불하지 않는다.
- 동행 능력을 스킬바 첫 칸에 우선 배치한다. 교체로 효과가 중복 적용되거나 HP가 회복되지 않게 한다. 쿨타임도 교체로 초기화하지 않는다.
- 액티브 미니몬 능력은 하나의 재사용 대기를 공유한다. 어느 능력을 지금 쓸지 선택하게 하고, 같은 효과의 다른 종을 번갈아 쓰는 우회를 막는다. 일반 액티브 능력의 개별 쿨타임은 유지한다.
- 첫 지역 미보유 마물은 해당 종 3회 처치부터 관심을 보장하고 첫 포획은 100%. 재포획 확률·천장·공명도는 유지한다. 값은 MinMonData.xlsx의 추가 컬럼으로 관리한다.
- 포획 결과 연출이 끝나면 기존 동행 버튼을 표시한다. 능력 설명에는 실제 효과·쿨타임·영구 습득 조건을 표시한다.
- 첫 처치로 도감에 기록되면 미보유 능력 효과도 미리 볼 수 있다. 포획할 대상을 효과로 선택하게 하되 미리보기는 사용 권한을 주지 않는다.
- 신규 공격/회복 능력은 EffectStat에 PhysicalAtk/MaxHp가 있으면 EffectValue를 해당 능력치의 백분율로 해석한다. 기존 빈 EffectStat 고정 효과는 유지한다.

## 결과

생성기는 `_tools/gen_minion_rewards.py --apply`, 이후 Unity `Tools/ParseAllLocal`로 JSON을 재생성한다. 기존에 공명도 100%를 달성했으나 능력 데이터 누락으로 보상을 못 받은 세이브는 로드 시 습득을 복구한다.

이 변경은 1~300레벨 전체의 재미나 밸런스 완료를 뜻하지 않는다. 검증 기준은 첫 포획 도달, 동행 교체에 따른 실제 전투 효과 차이, 영구화·기억력·쿨타임·저장 정합성이다. 정상 속도 플레이와 사용자 체감 평가는 별도 기록한다.
