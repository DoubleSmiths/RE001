# 0009. 모험가 등급을 완료한 협회 보고에 연결

- 상태: 채택
- 날짜: 2026-09-08

## 맥락

정상 플레이로 1급 보고(퀘스트 4)를 끝내고 퀘스트 6에 도달했지만 AdventurerRank는 0이었다.
등급 변경은 테스트 메뉴에만 있고, 실제 보고 버튼은 모든 보고 퀘스트에서 RANK UP 연출만 재생했다.

## 결정

QuestData의 BTN_GUILD_QUEST 완료 보고 하나를 승급 한 단계로 본다.
퀘스트 초기화·전환 시 현재 퀘스트보다 앞선 보고 개수를 세어 저장 등급을 보정한다.
이미 더 높은 저장 등급은 낮추지 않으며, 반복 초기화로 중복 승급하지 않는다.
등급 변경 이벤트로 HUD를 즉시 갱신한다.

## 결과

퀘스트 4 완료는 1급, 퀘스트 7 완료는 2급이다. 이후 기존 RANK UP 보고도 같은 규칙을 따른다.
보고 퀘스트가 향후 승급 없는 의뢰로 분리되면 데이터에 명시적인 승급 보상을 추가해야 한다.
검증: `_tools/verify_adventurer_rank.cs`로 저장값·HUD를 확인한다.
