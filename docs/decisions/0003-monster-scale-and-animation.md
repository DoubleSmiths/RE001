# 0003. 몬스터 500종은 "원형 + 절차적 애니메이션"으로 채운다

- 상태: 채택
- 날짜: 2026-08-14

## 맥락

목표는 몬스터 최소 500종이고 **각각 애니메이션이 있어야** 한다.
종별로 손으로 그린 스프라이트 시트(Idle/Attack/OnHit/Die) 500장을 확보하는 것은 현실적이지 않다.
반대로 애니메이터 3개를 500종이 돌려쓰면 "각각 애니메이션"이라 부를 수 없다.

지역도 문제였다. 신규 지역을 만들려면 배경 아트가 필요한데 기존 아트는 3개 지역분뿐이다.

## 결정

- **지역**: 새로 만들지 않고 기존 3개 지역에 depth 1~10 전투 노드를 추가한다(스프라이트 재사용).
  숲 Lv1~100 / 동굴 Lv101~200 / 성소 Lv201~300, depth2부터 `LEVEL_REQUIRED`로 잠근다.
- **외형**: 지역별 원형 스프라이트 30종만 생성(AetherForge). 종별 색조는 애니메이션 클립의
  색 커브로 준다 — 텍스처를 500장으로 늘리지 않으면서 심도·등급이 눈에 보이게.
  (심층일수록 짙게, 희귀=푸른빛, 보스=붉은빛)
- **애니메이션**: 몬스터마다 **전용 애니메이터 + 클립 5종**을 에셋으로 생성한다.
  `Editor/MonsterAnimGenerator`. Idle 호흡 스쿼시 / Run 바운스+기울기 / Attack 당겼다 돌진 /
  OnHit 붉은 플래시+밀림 / Die 납작해지며 소멸.
- **밸런스**: 플레이어 곡선 기준 상대값. HP = 플레이어 공격력 × 처치타수(일반5/희귀10/보스30),
  공격 = 플레이어 HP ÷ 22 + 방어, 경험치 = 요구경험치 ÷ 목표 처치수(Lv1 10킬 → Lv300 60킬).
  **골드는 경험치와 분리한 완만한 선형**이다. `RewardGold`가 int32라 지수 곡선이면 오버플로로
  파싱이 통째로 중단되고, 아이템 가격이 저작값이라 경제도 무너진다.

## 결과

- 상태명은 `Idle/Run/Attack/OnHit/Die`로 고정. `CreatureController`가 CrossFade로 부르는 이름과 같아야 한다.
- 심층 구간 안에서는 **경험치를 구간 대표 레벨로 통일**한다. 개체 레벨로 계산하면
  초반 등비 구간에서 같은 지역인데 효율이 5배까지 갈린다.
- ⚠️ 생성 루프를 `AssetDatabase.StartAssetEditing()`으로 감싸면 안 된다.
  `CreateAnimatorControllerAtPath`가 레이어를 온전히 만들지 못해 상태머신이 빈 컨트롤러가 나온다.
  **에셋 존재 확인만으로는 안 잡히고 클립 수까지 검증해야 드러난다.** (503개 전부 손상됐던 사고)
