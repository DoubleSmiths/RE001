# 0023. 직업 능력의 선택 비용과 실제 효과

- 상태: 채택
- 날짜: 2026-09-10

## 맥락

축성 미리보기를 열고 비교하니 강철의 기억(5004)은 최대 HP +50에 기억 4, 강인함(5125)은 최대 HP +120에 기억 2였다. 같은 숙련도 비용으로 같은 효과의 약한 능력을 선택하게 되는 구조였다. 연계 감각(5142)은 ComboKeep 값을 갖고 있었지만 콤보 시스템이 읽지 않아 기억력을 소비해도 효과가 없었다. 일부 직업 능력은 영어 이름·설명에도 한국어가 들어 있었으며, 조건 설명은 수치의 단계 배율과 다중 스탯을 표시하지 못했다.

## 결정

5004의 최대 HP +50은 유지하고 방어력 +5를 더한다. 기존 다중 스탯 열을 사용하며 기억 비용은 4에서 2로 낮춘다. 5125의 HP +120·기억 2는 유지한다. 두 능력은 같은 기억 비용에서 약한 반복 타격을 줄이는 방어와 큰 피해를 받아낼 체력을 비교하는 선택이다. 기존 저장에서 습득·기억·단계 정보는 그대로 읽으며, 비용 증가에 따른 기억력 초과를 만들지 않는다.

ComboKeep는 현재 데이터의 10×단계 값을 지속시간 증가율로 정의한다. 콤보 게이지의 감소량을 `dt / (1 + 보너스/100)`으로 바꿔 10%에서는 1.1배, 40%에서는 1.4배 오래 유지된다. 현재 게이지·타격 충전량·정규화 규칙은 유지하며 기억·망각으로 게이지를 다시 채우지 않는다.

직업 능력의 상세 본문은 실제 SkillData에서 스탯·효과 수치, 조건, 확률, 지속시간을 생성하고 번역 템플릿으로 표시한다. 미보유는 습득할 1단계 효과를 보여준다. 효과의 단계 배율은 런타임과 같아야 하며, 다중 스탯과 효과형 능력도 다음 단계 비교에 포함한다. 기존 능력 ID와 저장 구조는 바꾸지 않는다.

본문 길이가 변할 때는 기억 버튼·게이지까지 포함한 창을 다시 중앙 배치한다. 진입 슬라이드는 처음 열 때만 재생하고, 단계 미리보기·습득 후 갱신은 바로 위치를 맞춘다.

## 결과

수치·번역의 원천은 xlsx이며 `upgrade_class_choices.py`와 `class_ability_text.py`로 재현한다. 전체 스탯 적용, 기억 비용 환불, ComboKeep의 실제 Tick과 기억 해제, 한·영 설명·미리보기를 플레이 모드에서 검증한다.

지역 전투 시작 효과는 각 마물을 만날 때마다 반복되지 않는다. 치명 피해 직전 회복은 최대 체력에 제한되며 무조건 생존이나 부활이 아니다. 설명은 이 실제 동작을 넘어서는 보상을 약속하지 않는다. 수치 비교 검증과 외부 플레이어의 재미 평가는 별개로 유지한다.
