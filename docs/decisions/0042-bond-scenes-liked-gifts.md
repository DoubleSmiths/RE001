# 0042. 마을 사람 이야기 장면 · 좋아하는 선물

- 상태: 채택 (ADR0036 에서 뺀 '이야기 장면'·'좋아하는 선물')
- 날짜: 2026-09-30

## 맥락

포스트나이트2 는 호감도가 오르면 그 사람의 이야기(장면)가 열리고, 사람마다 좋아하는 선물이 있다. ADR0036 은 그림·대사가 필요하다며
둘 다 뺐다. 사용자 결정(2026-09-30): 빠진 재미 요소 네 가지 모두 넣기. 이미 있는 것: 대화창(`UI_DialoguePopup` — 대사 시트 +
화자 이름 + 초상화), 마을 건물마다 [대화] 버튼(평소엔 잡담 한 줄), NPC 초상화(접수원·연금술사는 대화창 애니메이터,
대장장이·사제·상점 주인은 마을 버튼 그림 — 어드레서블이 아니다).

## 결정

- **이야기는 그 사람의 [대화] 버튼에서** — 볼 차례인 이야기가 있으면 잡담 대신 처음부터 끝까지 튼다(찾아가 말을 거는 포스트나이트2 방식).
  초상화·말하기 신호(연금공방 `BTN_ALCHEMY_TALK` 등)는 기존 대화 코드를 그대로 쓴다. 퀘스트 대사(첫 협회 방문·연금공방 서브퀘스트)가 우선이다.
- **호감도 3·6·10단계에 한 편씩**(`BOND_SCENE_LEVEL_1~3`) — 5명 × 3 = 15편, 인물 말투대로(접수원: 딱딱하지만 챙긴다 / 연금술사: 장난·♡ /
  대장장이: 무뚝뚝한 반말 / 사제: 경건한 존댓말 / 상점 주인: 밝은 장사꾼). 1편 = 마음을 연다, 2편 = 사연, 3편 = 믿음.
  다 보면 크리스탈 30·60·150(`BOND_SCENE_CRYSTAL_1~3`). 본 기록은 `BondSaveData.ScenesSeen`(사람마다 몇 번째까지).
- **대사는 `DialogueData.xlsx` 의 시트**(`Bond{사람}{번호}Text`) — `_tools/gen_bond.py` 가 만든다(다른 시트는 건드리지 않는다).
- **좋아하는 재료**: 몬스터 재료 30종을 여섯 개씩(`BondNpcData.xlsx` — 접수원: 깃털·실크·꼬리털·광부의 유품·수정·기사의 문장 /
  연금술사: 젤리·독버섯·말벌 침·이끼·발광 점액·오염된 정수 / 대장장이: 송곳니·가죽·발톱·외피·비늘·가고일 돌 /
  사제: 석상·그림자·망령의 재·성물·환영·제단 / 상점 주인: 바람 정수·덩굴·날개막·갈기·수호자의 핵·공허 결정). 지역마다 고르게 나눠
  초반에도 하나씩은 얻는다. 선물은 **좋아하는 재료를 가진 게 있으면 그것부터**(가장 많은 것) 건네고 호감도 × `BOND_GIFT_LIKED_MULT`(2).
- 마을 탭 사람 줄: 볼 차례면 '새 이야기!', 좋아하는 재료를 줄 수 있으면 '♡ 재료 이름' + 선물 칸 ♡. 좋아하는 선물이면 알림
  '좋아한다! 호감도 +4'. 볼 차례인 이야기도 마을 탭 '!'·미션 버튼 점을 켠다(`HasReady`).

## 결과

- 실측: 접수원 3단계 → [대화] 에 이야기 1(5줄) → 크리스탈 +30, 다시 누르면 잡담 / 대장장이 6단계 → 이야기 1·2 차례로(+30·+60) /
  까마귀 깃털 선물 → 호감도 +4(좋아함).
- 이야기를 더 쓸 때는 `gen_bond.py` 의 `SCENES` 에 편을 더하고 `SCENE_COUNT`·`BOND_SCENE_LEVEL_n` 을 늘린다.
- 의상·전용 그림은 여전히 없다 — 이야기는 기존 초상화 한 장으로 말한다.
