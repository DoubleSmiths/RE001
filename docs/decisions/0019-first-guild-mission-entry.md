# 0019. 협회 첫 임무의 진입 버튼

- 상태: 채택
- 날짜: 2026-09-10

## 맥락

새 게임에서 협회를 방문한 뒤 [임무]를 누르면 '많이 한가하신가 보군요' 같은 잡담이 나왔다. 첫 퀘스트는 [대화]를 눌러야만 시작한다. 임무를 받으려는 자연스러운 선택이 진행과 무관한 응답으로 돌아가 초반 안내를 끊는다.

## 결정

첫 협회 퀘스트에서 [임무]도 기존 [대화]의 전체 안내와 완료 콜백을 사용한다. 대화 종료 전에는 진행시키지 않으며, 이후 보고 퀘스트의 데이터 기반 처리와 일반 잡담은 유지한다. 새 텍스트나 보상을 추가하지 않는다.

## 결과

두 버튼 어느 쪽으로 시작해도 같은 조건으로 임시 통행증과 여정 안내에 진입한다. 첫 안내 스펙의 버튼 제한보다 사용자의 자연스러운 목적을 우선한다. `_tools/verify_guild_entry.cs`로 라우팅을, 실제 새 게임 클릭으로 대화 종료와 여정 해금을 검증한다.
