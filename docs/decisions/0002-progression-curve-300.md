# 0002. 성장 곡선은 밴드형으로 설계한다 (1~300레벨)

- 상태: 채택
- 날짜: 2026-08-14

## 맥락

기존 `LevelData`는 40레벨까지였고 곡선이 **순수 등비 ×1.2**였다.
그대로 300레벨까지 늘리면 요구 경험치가 10^25에 달해 어떤 몬스터 경험치로도 도달할 수 없다.

더 근본적인 문제로, **스탯은 선형인데 요구 경험치는 등비**였다.
(`MaxHp = 100 + 20×(lv-1)`, `Atk = 15 + 3×(lv-1)`)
후반으로 갈수록 "레벨업해도 안 강해지는데 경험치만 폭증"하는 구조라 난이도가 붕괴한다.

## 결정

경험치·스탯 모두 **구간(밴드)별 성장률**로 설계한다. 생성기는 `_tools/gen_level_curve.py`,
`_tools/gen_player_status.py`.

- **Lv1~40은 기존 값을 그대로 보존한다.** 이미 플레이 검증된 초반 체감을 건드리지 않는다.
  (Lv40 요구경험치 122,481은 변경 전과 동일)
- Lv41부터 경험치 배율을 낮춘다: 1.12 / 1.09 / 1.07 / 1.055 / 1.045 / 1.035 → Lv300 ≈ 1.77조
- 스탯 증가폭은 반대로 키운다: HP +20 → +160/lv, ATK +3 → +20/lv → Lv300 HP 22,780 / ATK 2,982

## 결과

- 몬스터 스탯·경험치는 이 곡선의 **상대값**으로 잡는다([[0003]] 참조). 절대값을 손으로 넣지 않는다.
- 곡선을 바꾸면 몬스터 데이터도 함께 재생성해야 한다. 생성기가 같은 밴드 상수를 공유한다.
- `PlayerStatusData`에 `StartDef` 컬럼을 신설했다. 없으면 데이터 경로 전환 시 방어력이 0으로 퇴행한다.
