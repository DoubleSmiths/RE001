# 0020. 첫 동행은 모두 직접 쓰는 능력을 제공한다

- 상태: 채택
- 날짜: 2026-09-10

## 맥락
정상 속도 새 게임에서 첫 퐁이(2001)를 포획하고 동행시켰지만, 기존 능력 6001은 최대 체력 증가만 있어 전투에서 누를 새 행동이 없었다. 첫 지역 4종 중 기존 6001·6002와 신규 생성 능력의 보상 체감이 달랐다. 포획 화면은 CreatureData의 이름을 사용해 능력 목록의 실제 이름과도 달랐다.

## 결정
ADR 0014의 기존 패시브 보존 원칙을 유지하며 6001·6002에 수동 효과를 추가한다. 6001은 최대 체력 기준 회복, 6002는 일정 시간 공격속도 증가다. 기존 최대 체력·공격속도 패시브, 기억력, 최대 레벨, 이름과 아이콘은 보존한다. 효과 수치와 재사용 시간은 SkillData.xlsx에 두고, 기존 미니몬 공용 재사용 시간과 레벨 배율을 적용한다.

첫 포획 대상 2001·2002·2003·2101 모두 동행 즉시 능력 버튼을 제공한다. 첫 동행의 대여는 기억력을 소비하지 않으며 공명도 100%의 영구 습득과 구분한다. 포획 보상 이름과 아이콘은 능력 데이터의 이름·아이콘을 사용한다.

## 결과
`_tools/upgrade_starter_abilities.py`가 기존 두 행과 설명을 재현 가능하게 갱신한다. 기본은 dry-run이며 `--apply` 후 Unity 로컬 파싱이 필요하다. `_tools/verify_minion_rewards.py`는 첫 지역 4종의 수동 행동과 기존 패시브 보존을 함께 검사한다. 동행 해제 시 수동 버프와 대여 패시브가 모두 제거되어야 하며, 교체로 공용 재사용 시간을 우회하면 안 된다.
