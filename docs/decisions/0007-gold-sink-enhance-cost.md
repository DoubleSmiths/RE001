# 0007. 골드 소비처는 장비 강화 비용으로 만든다

- 상태: 채택
- 날짜: 2026-08-14

## 맥락

방치 보상([[0006]])으로 골드가 계속 쌓이는데, **소비처가 하나도 없었다.**
코드 전체에서 `Gold`가 줄어드는 곳은 테스트용 `TestGoldDecrease()` 하나뿐이었다.

골드가 순수 누적치면 "방치 → 성장" 순환이 끊긴다. 쌓이는 재화에 쓸 곳이 없으면
방치할 동기도 같이 사라진다.

## 결정

**장비 강화에 골드 비용을 붙인다.** 강화는 이미 순환의 중심이다
(강화 → 스탯 상승 → 더 깊은 심층 → 더 좋은 보상).

```
비용 = 120 × (다음단계)^1.8 × (1 + 등급 × 0.6)
```

- 단계가 오를수록 가파르게(^1.8) — 후반에 골드가 남아돌지 않게
- 상위 등급일수록 비싸게 — 티어를 건너뛰는 성장을 억제
- Basic 무기 +9까지 누적 약 23,000골드 / Mystic은 약 4배

`CanEnhance`가 잔액을 확인하고, `EnhanceEquipment`가 차감한다.
결과 구조체에 `GoldCost`를 실어 UI가 얼마 썼는지 보여줄 수 있게 했다.

## 결과

- 강화 UI는 `GetEnhanceCost(equip)`로 비용을 미리 표시해야 한다. 안 그러면 버튼이
  이유 없이 비활성으로 보인다. *(UI 표기는 후속 작업)*
- 몬스터 골드 보상([[0003]])을 바꾸면 강화 체감 속도가 함께 변한다.
  두 값은 같은 순환의 양쪽 끝이므로 한쪽만 조정하지 않는다.
- 골드 획득 능력(`GoldGain`)이 이 순환의 가속 장치가 된다.
