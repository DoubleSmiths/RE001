# 0033. 전투를 탭 공격으로 바꾸고 타격감을 코드로 입힌다

- 상태: 채택 (0030 의 '가드 입력 = 전투 화면 누르기'를 대체)
- 날짜: 2026-09-30

## 맥락

사용자: "타격감이 없으니까 게임이 밋밋해. 터치하면 공격하는 방식으로 변경해." "애니메이션쪽이 정상적이지 않아."
게임 화면을 프레임 단위로 떠서(`unity-cli exec` + `ScreenCapture`, 0.05~0.12초 간격) 본 사실:

- 공격은 전부 자동(1초 주기)이고 손은 가드뿐이었다. 한 번 벨 때마다 반응 없이 1초 클립이 끝까지 돌았다.
- 몬스터가 맞붙은 뒤에도 State 가 Moving 으로 남아 **첫 공격까지 제자리에서 계속 걸었다.** 다가올 때는 땅과 같은 속도(−5)로
  움직여 땅 위에 멈춘 채 걷는 모션만 도는 **러닝머신 걸음**이었다.
- 피격 색은 0.3초 동안 (1, 0.2, 0.2)로 물들었다 0.3초에 걸쳐 빠져, 연타하면 몬스터가 내내 **검붉은 덩어리**였다.
- 충돌 상자가 1칸 폭 고정이라 큰 몬스터가 **플레이어 칼·다리를 덮었고**, 타격 불꽃은 **발바닥(pivot)** 에서 튀었다.
- 원형 그림은 키를 전부 2칸(128px)에 맞춰 뽑아서(ADR0031) 납작하고 긴 것 — 슬라임 3.8칸, 지네 5칸 — 이 화면 절반을 덮었다.
- 플레이어·고블린 피격 클립의 첫 프레임은 흰 실루엣인데 **0.2초**(고블린 0.17초)나 머물러 통째로 하얗게 굳어 보였다.
- 쓰러진 몬스터는 마지막 프레임에서 뚝 사라졌다. 패링 기절 이모지는 받을 곳 없는 애니메이션 이벤트로 빨간 에러를 냈다.

## 결정

- **전투 화면을 누르면 벤다**(PC: Space·Z). 탭 공격은 공격 클립을 칼을 든 자세(정규화 0.235)부터 틀어 누른 뒤 약 0.09초에
  맞는다. 연타 상한 `TAP_ATTACK_INTERVAL` 0.28초(공격속도로 줄어듦), 베는 중 입력은 `TAP_INPUT_BUFFER` 0.25초 기억.
  적이 없으면 허공을 벤다 — 누르면 늘 반응한다. 판정은 코드가 잡고 클립 이벤트는 한 번 베기에 한 번만 들어온다.
- **AUTO 토글**(기본 꺼짐, `GameData.AutoBattle`): 켜면 예전 주기(AtkCooldown 1초)로 알아서 베고, 눌러도 된다.
  방치형 뼈대는 그대로다 — 오프라인·마을 방치 정산(ADR0006)은 전투 조작과 무관하다.
- **가드는 방패 버튼**(오른쪽 아래, PC: X·Shift)으로 옮긴다. 화면 탭이 공격이 됐으므로. 재사용 대기는 원형 덮개로 보이고,
  공격 예고 '!'마다 버튼이 들썩인다. 판정 규칙(ADR0030)은 그대로.
- **타격감**(연출 상수는 `Define` Hit Feel): 맞은 쪽·때린 쪽 애니메이터 히트스톱 0.05/치명 0.09/마무리 0.13초(전역 timeScale 은
  UIManager 가 전투 정지에 쓰므로 건드리지 않는다), 카메라 흔들림(설정 '화면 흔들림'을 따른다), 흰 실루엣 번쩍임 0.1초
  (`HitFlash`, 재질 SpriteSilhouette), 찌그러짐, 뒤로 밀림(마무리 일격은 날아가 쓰러짐), 데미지 숫자 즉시 1.6배(치명 2배) 튐 + 좌우 흩음.
- **애니메이션 교정**: 맞붙으면 Idle·물리 정지(Kinematic), 다가올 때 땅 대비 1.5 로 걸어옴, 공격 순간 앞으로 내디딤,
  쓰러지면 0.25초 페이드, 충돌 상자·타격점·머리 위 높이를 스프라이트 Tight 메시(실제 몸)로 잰다.
  몸 면적이 3.6칸²를 넘는 원형은 면적이 같아지게 줄인다(키 큰 인간형은 그대로, 키우지 않음).
  피격 클립의 흰 프레임은 0.06초로 줄인다(클립 길이 유지). 이모지 애니메이터는 이벤트를 끈다.
- 손을 놓는 시간을 줄인다: 처치 후 멈춤 2 → 0.8초, 다음 스폰 대기 2 → 1초.

## 결과

- 탭 전투 DPS 는 자동의 약 3배(0.28초 대 1초)다. 하루 성장은 오프라인 정산이 대부분이라(`sim_economy.py`: 보통 유저 하루
  처치의 90%) 곡선은 그대로 두었다. 보스 30초 제한은 손을 쓰면 넉넉하고 AUTO 만으로는 예전과 같다 — 손을 쓰면 확실히 이득.
- AUTO 를 끄고 두면 맞기만 하다 쓰러져 마을로 돌아간다(마을 방치 정산은 계속). 새 캐릭터에는 첫 맞붙음에 '눌러서 공격' 도움말.
- 애니메이터 속도를 바꾸는 코드는 `SetAnimSpeed` 를 거쳐야 한다 — `_anim.speed` 를 직접 쓰면 히트스톱이 풀리며 덮어쓴다.
- 몬스터 크기는 코드가 정한다(`FitBody`). 원형 그림을 다시 뽑아도 크기 규칙은 따라간다. 데이터의 `DamageFontYOffset` 은
  몬스터에는 더 이상 쓰이지 않는다(실제 머리 위로 다시 잰다).
- UI 는 `Tools/Remake V2/Build Battle Input` 이 만든다(그림 `_tools/gen_battle_buttons.py`). 예전 `UI_GuardInput`·
  `GuardTapArea` 는 지웠다. 되돌리려면 이 빌더를 되돌리고 `PlayerController.UpdateAttack` 의 탭 분기를 빼면 된다.
