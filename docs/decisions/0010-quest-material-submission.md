# 0010. 의뢰 제출은 표시된 요구량만 소비한다

- 상태: 채택
- 날짜: 2026-09-09

## 맥락

정상 진행에서 9번 의뢰는 슬라임 젤리 3개를 요구하지만 보유 재료 전량을 삭제했다.
초과 사냥분이 제작·강화에 쓰이지 못했다. `gen_quest_chain.py`는 수집과 보고에 같은 재료·요구량을 작성한다.
24개 보고의 ITEM_REMOVE는 FollowItemID와 일치한다. 4/7번은 별도의 증명서를 교체한다.

## 결정

완료된 의뢰의 FollowItemID와 회수 대상이 같으면 FollowCount만 소비한다.
다른 대상인 증명서 교체는 기존 전량 회수를 유지한다. 다음 의뢰로 넘어간 뒤 처리되므로 완료된 questId로 조회한다.

## 결과

초과 재료는 제작·강화·후속 의뢰에 재사용된다. 경험치 곡선이나 제작 가격을 임의로 낮추지 않는다.
별도 일괄 회수가 필요한 새 의뢰는 제출 재료와 구분해 설계해야 한다.
