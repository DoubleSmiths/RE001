# 0038. AUTO 는 첫 보스를 잡으면 열리고 켜진다

- 상태: 채택 (ADR0033 의 'AUTO 기본 꺼짐, 처음부터 토글'을 고친다)
- 날짜: 2026-09-30

## 맥락

탭 공격(ADR0033)에서 AUTO 는 처음부터 버튼이 있고 기본은 꺼져 있었다. 새 세이브로 따라가 보니 누르지 않는 새 유저는
첫 슬라임에게 8초 만에 HP 100 → 44 로 밀리고 쓰러졌다(도움말은 이제 누를 때까지 되풀이된다 — 257c6024).
반대로 AUTO 가 처음부터 있으면 켜 두고 손맛(ADR0033 의 목적)을 한 번도 안 느낄 수 있다.
사용자 결정(2026-09-30): "첫 보스를 잡은 뒤 AUTO 를 켜 주는 방식" 적용.

## 결정

- **첫 스테이지 돌파(첫 보스) 전에는 AUTO 버튼을 숨긴다.** 1-1 의 10마리와 보스는 눌러서 싸운다(실측 Lv3 가 5.5초/30초).
- **처음으로 스테이지를 돌파하는 순간 AUTO 가 열리고 켜진다** — `GameManager.ClearStage` 가 `GameData.AutoUnlocked` 를 세우고
  `AutoBattle = true`, 알림 '자동 전투가 열렸다! 이제 알아서 싸운다 · AUTO 로 끄고 켠다'. 이후 끄고 켜기는 유저 몫이고 다시 강제로 켜지 않는다.
- 전 세이브: 이미 AUTO 를 켜 봤거나 한 곳이라도 돌파했으면 열어 둔다(`NormalizeSave`). 둘 다 아니면 다음 첫 돌파 때 열린다.
- 자동 공격 자체는 여전히 `AutoBattle` 하나로 판단한다(`AutoUnlocked` 는 버튼과 첫 부여만 가른다) — 테스트·기존 경로 그대로.

## 결과

- 새 세이브 실측: 돌파 전 AUTO 버튼 없음·손대지 않은 14초 처치 0 → 1-1 보스 처치 → AUTO 열림·켜짐 → 손대지 않고 1-2 를 돌파해 1-3 에서 사냥(15초 처치 3 → 5).
- 도움말('눌러서 공격')은 AUTO 가 켜져 있으면 쉬므로 해금 뒤에는 뜨지 않는다.
