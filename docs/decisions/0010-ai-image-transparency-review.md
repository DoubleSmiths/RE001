# 0010. AI 이미지 결함은 알파 합성으로 판정하고 용도별 투명도를 검증한다

- 상태: 채택
- 날짜: 2026-09-29

## 맥락

몬스터 외 생성 이미지 401장을 점검했다. 일부 장비·스킬·재료는 배경 제거 과정에서
흰색·회색 내부까지 지워졌고, 완성 배경 9장에도 대규모 알파 결손이 있었다.
반면 NPC의 원본 뷰에 보이는 자홍색은 대부분 알파 0인 RGB여서 실제 화면에는 보이지 않았다.
색상 임계값만으로 결함을 판정하면 의도된 보라 장비·마법 문양까지 잘못 수정하게 된다.

## 결정

- 실제 알파를 밝은/어두운 배경에 합성해 검토한다. 자홍색 수치는 후보 탐색용으로만 사용한다.
- 사용자 선택대로 문제 이미지는 모두 내장 image_gen으로 재생성한다. 63장 교체 원본·프롬프트·
  이전 PNG는 `Documents/AIImageAudit`에 보관한다.
- 완성 배경은 알파 255 전체 채움을 요구한다. 중·근경 레이어 및 아이콘은 외곽 투명을 유지한다.
- 스킬 메달은 내부까지 불투명해야 한다. 내보내기 후 중앙 영역을 검사한다.
- 기존 파일 경로·크기·.meta를 보존한다. 배경 제거를 다시 적용하지 않고 생성 도구의 알파를 유지한다.

## 결과

원래 RGB가 남아 있어도 이 작업의 원천은 선택한 재생성 이미지다. 크기·여백 정리만
`inspect_ai_repairs.py`와 `export_ai_repairs.ps1`로 재현한다.
`verify_ai_repairs.py`는 투명도·PNG 내용·크기·메타 보존을 검사하지만 Unity 임포트와 플레이를 대신하지 않는다.
이 세션에서는 Unity Editor를 사용할 수 없어 인게임 검증이 남았다.
