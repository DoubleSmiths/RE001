# 결정 기록 (ADR)

여기 있는 문서는 **되돌리려면 근거가 필요한 결정**만 담는다.
다른 세션·다른 에이전트가 같은 고민을 처음부터 다시 하지 않도록 하는 것이 목적이다.

## 언제 ADR을 쓰나

쓴다:
- 데이터 원천, 곡선 설계, 에셋 파이프라인처럼 **뒤에 오는 작업이 따라야 하는** 결정
- 스펙이 모호하거나 상충해서 **한쪽을 골랐을 때** (기획서 vs 원본, 슬38 vs 슬49 등)
- 겉보기와 다르게 동작해서 **모르면 반드시 다시 밟는 함정** (어드레서블 라벨 규칙 등)

안 쓴다:
- 코드 읽으면 바로 보이는 것 (그건 주석)
- 한 번 쓰고 버리는 임시 처리

## 형식

`NNNN-짧은-제목.md`, 번호는 순번. 아래 4개 절만 채운다.

```markdown
# NNNN. 제목

- 상태: 채택 | 대체됨(→ NNNN) | 폐기
- 날짜: YYYY-MM-DD

## 맥락
무엇 때문에 결정이 필요했는가. 관측한 사실 위주로.

## 결정
무엇으로 정했는가.

## 결과
이 결정 때문에 이후 작업이 무엇을 지켜야 하는가. 되돌릴 때 무엇이 깨지는가.
```

바뀐 결정은 파일을 지우지 말고 상태를 `대체됨`으로 바꾸고 새 번호를 가리킨다.
