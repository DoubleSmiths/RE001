# 0011. 현재 여정과 직업 능력 규칙

- 상태: 채택
- 날짜: 2026-09-09

## 맥락

7월 여정 문서는 승급 보고로 지역을 해금한다고 설명하지만, 이후 생성기와 현재 엑셀/JSON은 148개 LEVEL_REQUIRED 조건으로 확장됐다.
155개 노드(마을5/지역25/전투125)가 있고 `gen_world.py`, `gen_monsters.py`, `gen_quest_chain.py`가 레벨 조건을 공유한다.
PlayerStatusData 300행의 직업은 Traveler이며, 실제 수도원은 처치로 쌓은 숙련도를 소비해 Class 출처 능력을 습득한다.

## 결정

현재 플레이 가능한 범위는 여정 버튼 해금 후 레벨 조건으로 지역을 연다. 상위 레벨 도달 후 하위 지역은 계속 이용할 수 있다.
증명서 교체로 지역을 다시 잠그지 않는다. 미해금 지역의 표시 방식은 기존 UI를 유지한다.
직업은 Traveler를 기본으로 유지하며 수도원 축성은 직업 능력 습득으로 정의한다. 별도 직업 변경·전용 스탯 분기는 추가하지 않는다.

## 결과

이 문서가 7월 `Travel_Unlock_Changes_1.txt`의 QUEST_CLEAR 지역 게이트 설명을 대체한다.
전투 데이터·조건의 원천은 로컬 엑셀이다. 새 직업 전환을 넣을 때는 직업별 스탯과 저장 마이그레이션을 함께 설계한다.
화면에는 축성/직업 능력을 사용해 실제 기능을 설명한다. `audit_progression.py`와 실제 축성5004 습득으로 현재 연결을 검증했다.
