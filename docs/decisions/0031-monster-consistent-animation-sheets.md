# 0031. 몬스터 5동작을 한 시트로 저작하고 고정 캔버스로 교체한다

- 상태: 채택
- 날짜: 2026-09-29

## 맥락

기존 몬스터 아키타입 30종의 동작별 `_raw_*.png`는 각기 다른 배경·크기·방향으로 생성됐다.
실제 슬라임 프레임에는 회색 배경이 남았고, 바람 정령 등에는 자홍색 배경의 잔여물이 있었다.
까마귀 idle 원본은 프레임 사이에 좌우 방향까지 달랐다.
기존 배경 제거와 등분·내용 추정 방식만으로는 서로 다른 동작의 외형을 일치시키기 어렵다.

## 결정

- 내장 image_gen으로 원형마다 4열 × 5행 시트를 저작한다. 한 시트에서 캐릭터 외형과 배율을 공유한다.
- 행 순서는 Idle / Move / Attack / Die / OnHit. 게임 상태명 Run은 Move 파일에 계속 대응한다.
- 새 원본과 실제 프롬프트는 `Documents/MonsterRemaster/sheets` 및 `manifest.json`에 보관한다.
- `_tools/inspect_monster_sheets.py`가 알파 영역을 읽어 경계를 검사한다. 캐릭터 사각형이 겹치면
  임의 등분하지 않고 재생성한다. 검사 결과는 `frame-plan.json`이다.
- `_tools/export_monster_frames.ps1`로 384×256 RGBA, 하단 중앙, Point 리샘플링으로 분리한다.
  몬스터당 idle 높이 중앙값을 128px에 맞추는 단일 배율을 전체 20프레임에 적용한다.
  사망·피격 포즈를 프레임별로 확대하지 않는다. 출력 한계를 넘으면 전체 배율을 함께 줄인다.
- 기존 PNG 파일명과 `.meta`를 유지한다. 컨트롤러·클립·Addressables를 재생성하지 않는다.
- 원형 아이콘 30장과 이 원형을 쓰는 도감 카드 500장은 같은 새 idle에서 파생한다.
  `gen_moncards.py`에 정의된 등급별 색상 규칙을 유지한다. 레거시 카드 3장은 대상에서 제외한다.

## 결과

현재 아키타입 프레임의 재현 원천은 새 통합 시트다. 기존 `_raw_*.png`는 과거 원본으로 남으며,
`remaster_anim.py` / `reslice_anim.py`를 다시 실행해 현재 프레임을 덮어쓰면 수정이 사라진다.
갱신 시 새 검사·내보내기 경로를 사용한다.
오프라인 PNG·GUID 검사는 Unity 실제 Sprite 로드와 플레이 검증을 대체하지 않는다.
이 세션에서는 Unity Editor 및 문서에 명시된 unity-cli 실행 파일이 없어 해당 검증을 수행하지 못했다.
