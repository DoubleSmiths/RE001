상태정보(Status) Popup   #4
능력치
능력 상세정보:
*모든 전투와 보조에 관련된 능력치들이 표시됨
*괄호()안에 수치는 초기 설정 수치
*치명타, 물리저항, 마법저항, 회피율은 100%가 넘어갈 시 표기는 넘은 그대로 하되 적용은 100%까지만 적용.
*표기 시 소수점이 생기면 괄호()안에 표기된 소수점까지만  반올림하여 표기 및 적용.
소수점 없을 경우 소수점 표기 X
1. 물리공격력: 물리타입 공격들의 피해량에 영향 (10)
2. 마법공격력: 마법타입 공격들의 피해량에 영향 (10)
3. 치명타: 공격이 치명타로 적중할 확률 (0.00%) 100% 이상 수치가 가능하나 적용은 100%까지만.
4. 치명타피해: 치명타로 적중 시 표기된 %로 피해량을 곱하여 피해를 줌 (150%) 즉 150%면 1.5배
5. 명중률: 공격이 적에게 적중할 확률 (80.0%)
6. 공격속도: 기본공격 1회 Anim의 Speed. (100%)
※ 이곳에는 표시하지 않지만, 피해증폭률이 존재한다.
방어력과 저항에 감소되기 전 피해량에 피해증폭률을 곱하여 계산.
7. 최대체력: 신체 내구력. 0이 되면 사망.
8. 방어력: 모든 타입의 최종 피해량에서 방어력의 수치만큼 최종 피해량을 감소.
최종 피해량은 음수(-)가 될 수 없음. (0)
9. 물리저항: 물리 타입의 피해를 받을때 해당% 만큼 피해량을 감소. (0.00%)
10.마법저항: 마법 타입의 피해를 받을때 해당% 만큼 피해량을 감소. (0.00%)
11.회피율: 모든 타입의 공격을 해당% 만큼 회피하여 피해를 무시. (0.00%)
12.회복력: 체력회복에 관련된 모든 효과를 표기된 %로 곱하여 적용. (0.0%)
13. 성장률: 레벨 경험치 획득 시 표기된 %로 곱하여 적용. (100%)
14. 획득률: 몬스터 드랍률 표기된 %로 곱하여 적용.(100%)
해당 속성은 플레이어만 적용.
그 외 능력치들은 몬스터에게도 동일 적용.

예시 화면
몬스터 사망
1. 어떤 방식으로 든지 몬스터의 현재 HP가 0 이하로 떨어지게 되면 몬스터는 사망하게 되며 전투가 종료된다.
- 몬스터 사망 시 해당 몬스터는 Die Clip 재생.
- Monster HP Bar는 Playbackwards로 Dotween 재생.
- 대기 상태로 진입.
2. 몬스터의 전리품(Drop Item, 돈 포함)의 확률 주사위 진행.
- 만약 성공 시 아이템 획득 리스트 UI에 표시.
3. 경험치 증가 및 레벨업 체크.
- 레벨업 시 Levelup Event 진행 (다음 슬라이드)
4. 해당 몬스터의 Kill count 가 1 증가.
- 해금 요소 체크 (나중에 이팩트 넣을 수도)
5. 몬스터 관심 체크.
- 성공 시 관심 대기열 확인.
- 자리가 있다면 대기열에 추가.
6. Die Sound 재생.

예시 화면
Level Up
[IMG: 그림 4]
1. 몬스터 사망 후 만약 Player의 경험치가 현재 Level의 요구 경험치보다 높거나 같을 경우
왼쪽의 예시 화면과 같이 Level up Event를 진행한다.
2. Level up Event:
2-1. Player Level up UI 호출 (Player Level Up Text.prefab    = Google Drive 에 있음)
2-2. Player Level up Effect 호출 (Player Level Up Ef.prefab   = Google Drive 에 있음)
2-3. (예시화면에는 적용이 안되어있지만) Player의 Now HP를 Max HP까지 회복. (회복할때처럼 HP Text 초록색 효과 주기)
2-4. 현재 경험치 조정, Player EXP Bar 에도 적용.
2-5. Player Level 조정. Player Bar 에 있는 Player Level Text 에도 적용.
2-6. 하단 [상태] Button에 [ + ] icon (이미 active 상태면 Dotween Restart), (active 상태가 아니라면 active 및 Dotween Restart)
