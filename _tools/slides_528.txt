도감 기획서   #2
상단 UI 기능
[IMG: 그림 2]
[IMG: 그림 12]
1. 완성도란에 있는 4개의 아이콘(버튼)들은
플레이어의 기술들이다.
2. 각 기술들은 가장 왼쪽부터 오른쪽 순으로:
1. 종을 초월한 교감
2. 조련사의 기술
3. 오다 주웠습니다 주인님!
4. 기억 확장
3. 게임 시작 시 가장 오른쪽에 있는 기술인
“기억 확장”을 제외한 나머지 기술들은 잠금 상태이다.
4. 도감은 몬스터별로 각 별(star)단계가 존재,
최고 별단계(보라색 별)를 달성 시 가장 왼쪽 부터
시작하여 오른쪽 순으로 하나씩 1등급이 오르게 된다.
가장 오른쪽에 위치한 “기억 확장“ 등급이 오르게 되면
다시 가장 왼쪽에 위치한 “종을 초월한 교감“ 기술
차례로 된다.
예시 화면
도감을 열어놓은 상태에서
어떤 몬스터의 별 등급이
올랐을 때의 예시.
(이에 대한 자세한 내용은
#5 에 서술)
5. 별단계에 대해서는 도감 기획서 다음에 작성할
[미니몬 기록] 기획서에 서술 예정.
6. 잠금 상태의 아이콘(버튼)은 Interactive가 불가하다.
7. 해금된 상태의 아이콘(버튼)은 Interactive가 가능하며
아이콘 클릭 시 해당 [기술 상세정보창]을 호출한다.
8. 밑에 “+0 등급”은 마물 도감을 통해 추가적으로 얻은
추가 등급을 명시하고 있다.
그래서 [기억 획장] 기술은 처음부터 해금되어 있는
상태이며, 표기도 +0 등급으로 표기하는 것이다.
마찬가지로 나머지 다른 3개의 기술을은
마물 도감으로만 획득이 가능하기 떄문에
잠금 상태로 적용한다.
9. 아이콘의 Anim 과 적용방식은 추후 하단 UI
기능에 기술되어 있음.

해당 미니몬과
함께 다닐 때
[ 나의 미니몬 ] 창에서 [ 부르기 ] 버튼을 통해 해당 미니몬과 동행할 수 있게 된다.
- 이 [ 부르기 ] 버튼은 해당 미니몬과 동행할때와 동행하고 있지 않을 때의 버튼이 다르다.
[ 부르기 ] 버튼을 누를 시 해당 미니몬과 동행하게 된다.
- 이때 이미 다른 미니몬과 동행하던 상태이면 동행중이던 미니몬과 자동으로 헤어지고 해당 미니몬과 동행하게 된다.
- [ 부르기 ] 버튼은 [ 동행중 ] 버튼으로 변한다.
- 또한 [ 나의 미니몬 ] 창에 [ Flash_USETHIS ] 효과가 들어가며, [ 미니몬 기록 ] 창과 [ 미니몬 도감 ] 의 UI 도 함께 갱신된다.
- [ 나의 미니몬 ] 창이 현재 동행하고 있는 미니몬일 시 [ 나의 미니몬 ] 창에 [ Active Ef ] 효과가 들어간다.
- 동행하는 미니몬의 위치는 미니몬마다 다르다.
- 동행하는 미니몬은 플레이어를 따라 Idle, Run Anim 을 같이 재생한다.
- 동행하는 미니몬은 전투 시 자신의 공격속도 (공격대기시간)에 따라 자동으로 공격한다. (Attack Anim)
- 동행 미니몬이 공격 시 명중률만 플레이어의 명중률을 따른다.
- 동행 미니몬의 DMG TEXT 는 플레이어와 동일하다.
- 동행 미니몬의 공격 또한 [ 타격 ] 으로 친다. ( 공세 단계 및 게이지에 영향 )
- [ 미니몬 사용 기술 ] 은 해당 미니몬과 동행했을때 미니몬이 자동으로 사용하는 기술이다.
- ※ 추후 기술을 통해 동행하는 미니몬 수가 늘어날 수 있음. (아마도..)

능력   #1
기본 정보
일반적으로 다른 게임에서 [ 스킬 ] 이라고 표현하는 것이 [ 능력 ] 이다.
능력의 종류:
1. 유틸리티 (ex. 미니몬 잡기 성공 확률 증가, 확정 미니몬 잡기 필요 횟수 감소, 경험치 획득량 증가 등등)
2. 전투: (ex. 전투 관련 능력치 수치 증가, 전투 기술 및 마법 등등)
3. 편의성: (ex. 자동물약, 미니몬 관심 최대 수 증가 등등)
기억력과 재능:
1. 플레이어는 [ 기억력 ] 이라는 수치를 가지고 시작함.
2. 모든 능력은 [ 기억력 점유량 ] 을 갖고 있음.
3. 플레이어는 해당 [ 기억력 점유량 ] 만큼의 [ 기억력 ] 을 점유(사용)해 능력을 기억(적용) 시킬 수 있음.
4. 기억중인 능력을 잊을 시 해당 능력의 [ 기억력 점유량 ] 만큼 [ 기억력 ]을 회복한다.
5. 만약 능력의 [ 기억력 점유량 ] 이 0일 시 해당 능력은 재능으로 치며 항시 기억(적용)중인 상태이다.
[IMG: 그림 12]
능력 획득 방식:
1. 장비 +9 강화 시.
2. 미니몬 공명도 100% 시.
3. 특정 NPC에게 재료를 주고.
4. 전직 시.
5. 도감 별 작업.
능력 단계:
1. 모든 능력은 단계(Level)가 있다.
2. 단계는 아래와 같은 방법으로 올릴 수 있으며, [ 기억 확장 ] 능력만 제외하고 각 능력마다 하나의 방법만 적용이 된다.
a. 1. 장비 +9 강화 시.
b. 미니몬 공명도 100% 시.
c. 특정 NPC에게 재료를 주고.
d. 전직 시.
e. 도감 별 작업.
f. 미니몬 사냥.
[ 기억 확장 ] : 최대 기억력 올려주는 재능 기술
장비 능력
1. 장비 착용 시 해당 장비의 능력을 기억한다. ( 기술창에 표시 )
2. 이때 기억하는 능력은 [ 기억력 ] 을 점유하지 않고 기억한다.
3. 해당 장비를 착용 해제 하면 기억하던 능력도 사라지게 된다. ( 기술창에서 없어짐 )
4. 만약 장비가 +9 강화에 도달하게 된다면, 해당 장비의 장비 능력은
플레이어의 기술창에 남게 되며 해당 장비를 해제해도 능력이 사라지지 않지만 (기억은 해제 됨)
[ 기억력 점유량 ] 만큼 [ 기억력 ] 을 점유하여 해당 능력을 기억하여 사용해야 한다.
5. 이때, +9 강화 장비를 다시 착용하게 되면 해당 장비 능력이 자동으로 [ 점유량 ] 소모 없이
기억하게 된다. ( 이미 기억하고 있었다면 환불 )
