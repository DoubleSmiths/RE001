# project-ai outputs

이 폴더는 기능별 기획 검증 산출물을 쌓는 용도다.

디렉터리 용도:
- `architecture/`: 운영 방식, 실행 순서, 역할 분리 문서
- `spec/`: 기능별 브리프, 분석 AI 입력문, 총괄 통합본
- `checklist/`: 기능별 QA 체크리스트
- `code_review/`: 구현 AI 결과 요약, 수정 범위 메모

현재 추가된 파일:
- `architecture/phase1_dual_ai_runbook.md`
- `spec/01_popup_common_brief.md`
- `spec/02_quest_system_brief.md`
- `spec/03_inventory_item_detail_brief.md`
- `spec/04_potion_popup_brief.md`
- `spec/05_travel_popup_brief.md`
- `checklist/phase1_master_checklist.md`

운영 규칙:
- 기준 문서는 항상 `Documents/기획안/기획서v2_04.16.pptx`
- 기능 하나당 `분석 AI -> 구현 AI -> 총괄 통합` 순서로 끝낸다.
- 각 기능 문서의 `Spec Writer Input`, `Implement Reviewer Input` 블록을 그대로 복사해 사용할 수 있다.
