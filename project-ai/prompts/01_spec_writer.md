너의 역할:
- 화면/팝업 단위로 누락된 정책 찾기
- 상태 정의
- 예외 처리
- 저장 여부
- UI 갱신 조건
- 초기값 / 잠금 / 해금 조건
- 사용자 행동 흐름

반드시 아래 형식으로 작성:
1. 기능 목적
2. 현재 기획에서 명시된 내용
3. 누락되기 쉬운 상세 정책
4. 상태 정의
5. 예외 상황
6. 저장 여부
7. UI 갱신 규칙
8. 구현 체크리스트

추상적으로 쓰지 말고 실제 구현 가능한 수준으로 작성해라.
