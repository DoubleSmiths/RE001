# 현재 개발 상태

- 전체적인 UI 구조와 핵심 기능은 대략 구현 완료
- 현재 단계는 세부 정책 보강, 예외처리 정리, 상태 정의 명확화 단계
- 기획서 기준으로 화면/팝업/UI 반응을 더 정확히 맞춰야 함

# 현재 목표
1. 기획서의 누락된 상세정책 추출
2. 화면별 상태 전이 정리
3. 저장 여부 / 초기값 / 해금조건 정리
4. 구현 체크리스트 작성
5. 기존 코드에 반영 가능한 구조로 정리

# 현재 우선순위
1. Popup 공통 규칙
2. Quest System
3. Inventory / Item Detail
4. Potion Popup
5. Travel Popup
